Introduction to the FIPPI Algorithm

The Fast Iterative Pixel Purity Index (FIPPI) is an effective method for extracting endmember signatures from hyperspectral remote-sensing data. It is an iterative improvement of the pixel purity index (PPI), designed to improve computational efficiency and obtain better endmember estimates through a sound stopping condition and carefully designed iteration rules.

Mathematical Principles of the Algorithm

Dimensionality Reduction

In the FIPPI algorithm, the original high-dimensional data cube is first reduced in dimension in order to lower computational complexity. Common dimensionality-reduction methods include:

  1. Principal component analysis (PCA): project the high-dimensional data into principal-component space and retain the principal information.

  2. Maximum noise fraction (MNF) transform: order the components by image quality and retain the high-quality components.

For the original data matrix \(\boldsymbol{X} \in \mathbb{R}^{m \times n}\), dimensionality reduction produces \(\boldsymbol{X}^{*} \in \mathbb{R}^{m \times p}\), where \(p < n\).

Automatic Target Generation Process (ATGP)

The ATGP algorithm estimates the initial endmember set from an orthogonal subspace projection. Given the dimensionality-reduced data

\(\boldsymbol{X}^{*}\), which contains \(p\) feature vectors, the ATGP algorithm is as follows:

  1. Find the index \(i_1\) of the first endmember vector that maximizes

\(\sum_{j=1}^{p} (\boldsymbol{x}_j^*)^2\), that is, \(\boldsymbol{u}_1 = \boldsymbol{x}_{i_1}^*\).

  1. For the \(k\)th (\(k \geq 2\))

endmember vector, solve:

\[ \boldsymbol{u}_k = \arg\max_{\boldsymbol{x}_j^*} \left\|\left(\boldsymbol{I}_p - \boldsymbol{U}_{k-1}\boldsymbol{U}_{k-1}^+\right)\boldsymbol{x}_j^*\right\|^2 \]

where

\[ \boldsymbol{U}_{k-1} = \begin{bmatrix}\boldsymbol{u}_1 & \boldsymbol{u}_2 & \cdots & \boldsymbol{u}_{k-1}\end{bmatrix} \]

, and \(\boldsymbol{U}_{k-1}^+\) is the pseudoinverse of \(\boldsymbol{U}_{k-1}\).

The algorithm repeats the process above until \(p\)

initial endmember vectors are obtained.

FIPPI Iteration Rules

After the initial endmember set \(\boldsymbol{U} \in \mathbb{R}^{p \times p}\) is obtained with the ATGP algorithm, FIPPI refines it according to the following iteration rules:

  1. Project the dimensionality-reduced data onto the current endmember space: \(\boldsymbol{Y} = \boldsymbol{U}^T\boldsymbol{X}^*\)

  2. For each sample, find its maximum absolute projection value in the projected space and the corresponding sample index

\(i_j\):

\[ i_j = \arg\max_{1 \leq i \leq m} \left|\boldsymbol{y}_i\right| \]

  1. Construct the extrema set \(\boldsymbol{X}^{ext} = \left\{\boldsymbol{x}_{i_j}^*\right\}_{j=1}^q\), where \(q\) is the number of extrema.

  2. Check the stopping condition: if \(\boldsymbol{X}^{ext} \subseteq \boldsymbol{U}\), stop the iteration; otherwise, add to \(\boldsymbol{U}\) the vectors in \(\boldsymbol{X}^{ext}\) that are not already in \(\boldsymbol{U}\), and return to step 1 to continue iterating.

After several iterations, the algorithm outputs \(\boldsymbol{U}\) as the estimated endmember set.

function endMembers = fippi(cube, num, option)
% fippi extracts endmember signatures from a hyperspectral data cube using the Fast Iterative Pixel Purity Index algorithm.

%   ENDMEMBERS = FIPPI(CUBE, NUM) estimates endmember signatures by projecting the dimensionality-reduced data onto the initially estimated endmembers.
%   NUM is the number of endmember signatures present in CUBE. CUBE is an M-by-N-by-C numeric array containing hyperspectral data, or
%   a hyperspectral data cube object. M and N are the numbers of rows and columns of the hyperspectral data cube, respectively. C is the number of bands in the hyperspectral data cube.
%   NUM must be a nonzero positive integer. The output ENDMEMBERS is a numeric matrix that provides the C-by-K endmember signatures, where K is
%   the size of the final endmember set estimated according to the stopping condition.

%   ENDMEMBERS = FIPPI(___,Name, Value) estimates endmember signatures by projecting the dimensionality-reduced data onto the initially estimated endmembers.
%   Two methods are available for dimensionality reduction, with the following parameters:
%
%   'ReductionMethod' - Method used to reduce dimensionality. The options are:
%
%       'PCA'  Principal component analysis (PCA), based on maximum data variance. It converts large-scale data to a smaller scale
%             while retaining most of the information.
%
%       'MNF'  Maximum noise fraction (MNF) transform, based on the noise fraction. It converts large-scale data to a smaller scale
%             while retaining most of the information. MNF orders components according to image quality.
%             The MNF method is used by default.
%
%   Notes
%   -----
%   1) FIPPI is an iterative algorithm. The iteration rule is designed to improve the result at each iteration until the final endmember set is reached.
%   2) The FIPPI output is not necessarily NUM endmembers. It outputs K endmembers according to the FIPPI stopping condition.
%   FIPPI uses a replacement rule to refine each iteration and stops when the final set of skewers no longer contains new endmembers.
%   3) The NUM input argument helps estimate the initial endmember set with the automatic target generation process (ATGP).

%   Class Support
%   -------------
%   The input array CUBE must be one of the following types: uint8, uint16, uint32, int8, int16,
%   int32, single, double, uint64, int64, or a hyperspectral data cube object.
%   It must be real and nonsparse. The output ENDMEMBERS is a C-by-K numeric matrix.

%   References
%   ----------
%   CI Chang, A. Plaza, "A fast iterative algorithm for implementation of
%   pixel purity index", IEEE Geoscience and Remote Sensing Letters,
%   volume-3, pages: 63-67, 2006.

%   Example 1: Find endmember signatures
%   -----------
%   % Load the indianpines data set
%   cube = load('indian_pines.mat');
%
%   % Estimate the number of endmembers
%   num = countEndmembersHFC(cube.indian_pines);
%
%   % Estimate and visualize endmember signatures with the FIPPI algorithm
%   endMembers = fippi(cube.indian_pines, num);
%   plot(endMembers);
%   xlabel('Band index')
%   ylabel('Signatures')
%   title('Endmembers')

%   Example 2: Find endmember signatures using the 'PCA' dimensionality-reduction method
%   -----------
%   % Read the hyperspectral data cube
%   obj = hypercube('indian_pines.hdr');
%
%   % Estimate the number of endmembers
%   num = countEndmembersHFC(obj);
%
%   % Estimate endmember signatures with the FIPPI algorithm
%   endMembers = fippi(obj, num, 'ReductionMethod', 'pca');
%   plot(endMembers);
%   xlabel('Band index')
%   ylabel('Signatures')
%   title('Endmembers')
%
%   See also ppi, nfindr, hypercube, and countEndmembersHFC.

%   Copyright 2020-2021 The MathWorks, Inc.

arguments
    cube {mustBeA(cube,'hypercube')}
    % cube must be a hyperspectral data cube
    num (1,1) {mustBeNumeric, mustBeNonNan, mustBeFinite, mustBeNonsparse, ...
        mustBeNonempty, mustBeReal, mustBeInteger, mustBePositive, ...
        mustBeLessSize(num, cube)}
    % num must be a positive integer and smaller than the number of bands in the data cube
    option.ReductionMethod (1,1) string ...
        {validatestring(option.ReductionMethod,{'MNF', 'PCA'})} = "MNF"
    % option.ReductionMethod is a string that specifies the dimensionality-reduction method; the default is 'MNF'
end

% Required for compiler tests
if isdeployed
    rootDir = ctfroot;
else
    rootDir = matlabroot;
end
% Register resources/hyperspectral data
matlab.internal.msgcat.setAdditionalResourceLocation(rootDir);

% Parse the inputs
if isobject(cube)
    cube = cube.DataCube;
end

method = validatestring(option.ReductionMethod, {'MNF', 'PCA'});

% Get the size of the data cube
[rows, cols, channels] = size(cube);
numofPixels = rows*cols;

% Reshape the data cube for signature extraction
originalCube = reshape(cube, numofPixels, channels);

if isinteger(cube)
    cube = single(cube);
    num = single(num);
end

if strcmpi(method, 'PCA')
    % Perform principal component analysis (PCA) on the hyperspectral data cube
    cube = hyperpca(cube, num);
    
else 
    % The maximum noise fraction (MNF) transform determines the intrinsic dimensionality of the image data, removes noise from the data, and reduces the computational requirements
    cube = hypermnf(cube, num);
end

% Initialize the skewers with the ATGP algorithm
initializeSkewers = atgp(cube,numofPixels, num);

% FIPPI algorithm
stoppingCriteria = false;
cube = reshape(cube, numofPixels, num);

% The stopping condition is used to find the final endmembers
while ~stoppingCriteria
    
    % Project the dimensionality-reduced data onto the initially estimated endmembers
    projPoints = abs(initializeSkewers*cube');
    
    % Find the extreme locations to form the extrema set
    [~, maxLoc] = max(projPoints,[], 2);
    maxLoc = unique(maxLoc);
    
    % Check the new endmember set
    stoppingCriteria = all(ismember(cube(maxLoc,:), initializeSkewers), 'all');
    initializeSkewers = unique([cube(maxLoc, :);initializeSkewers],'sorted','rows');
end

endMembers = originalCube(maxLoc, :)';
end

function U = atgp(dimRed, numVariables, num)
% The automatic target generation process (ATGP) estimates the initial signature set from an orthogonal subspace projection

% Reshape the dimensionality-reduced data cube
dimRed = reshape(dimRed, numVariables, num)';

% Find the index of the first signature
[~, idx] = max(sum(dimRed.^2));

% Initialize and obtain the first endmember signature
U = zeros(num, class(dimRed));
U(:,1) = dimRed(:,idx);

for n=1:num-1
    % Maximum absolute orthogonal subspace projection
    [~, idx] = max(sum(((eye(num) - (U * pinv(U)))*dimRed).^2)); 
    U(:,n+1) = dimRed(:,idx);
end
end

function mustBeA(hypercube,classIn)

if isobject(hypercube)
    validateattributes(hypercube,{classIn},{'nonempty'},'fippi','hypercube');
else
    validateattributes(hypercube, ...
    {'uint8','int8','uint16','int16','uint32','int32','single','double', 'uint64', 'int64'},...
    {'nonsparse', 'nonempty', 'real','nonnan', 'finite', 'ndims',3}, mfilename, 'hypercube', 1);
end

end

% Validate that numComponents is smaller than the number of bands
function mustBeLessSize(a, b)
if isobject(b)
    cube = b.DataCube;
else
    cube = b;
end
sz = size(cube);
validateattributes(a, {'numeric'},...
    {'>', 0, '<=',sz(3),'scalar'},mfilename, 'num',2);

if (a >= sz(1)*sz(2))
    error(message('hyperspectral:hyperpca:notGreaterEqual'));    
end
end

Summary

Through a sound mathematical model and carefully designed iteration rules, the FIPPI algorithm effectively extracts endmember signatures from hyperspectral remote-sensing data. It overcomes several shortcomings of the conventional PPI algorithm, improves computational efficiency and endmember estimation accuracy, and is a powerful tool for endmember extraction in remote sensing.
