When reading txt files, you often encounter delimiters other than whitespace. read_table has a sep parameter that lets you customise the delimiter used to parse a txt file. For example, the table read below is delimited by ||||:

1

pd.read_table('../data/my_table_special_sep.txt')

col1 |||| col2
0TS |||| This is an apple.
1GQ |||| My name is Bob.
2WT |||| Well done!
3PT |||| May I help you?

The result above is clearly not what we want. You can use sep instead, specifying python as the engine:

1

pd.read_table('../data/my_table_special_sep.txt', sep=' \|\|\|\| ', engine='python')

col1col2
0TSThis is an apple.
1GQMy name is Bob.
2WTWell done!
3PTMay I help you?

[WARNING]sep is a regular expression parameter

When using read_table, keep in mind that sep is interpreted as a regular expression, so you must escape | as \| or the data will not be read correctly. For the basics of regular expressions, see Chapter 8 or other reference material.

[END]

2. Writing Data

When writing data, the most common operation is to set index to False, particularly when the index carries no special meaning; doing so drops the index from the saved file.

1
2

df_csv.to_csv('../data/my_csv_saved.csv', index=False)
df_excel.to_excel('../data/my_excel_saved.xlsx', index=False)

pandas does not define a to_table function, but to_csv can write txt files and allows a custom delimiter — a tab \t is commonly used:

1

df_txt.to_csv('../data/my_txt_saved.txt', sep='\t', index=False)

To convert a table quickly into markdown or latex, use the to_markdown and to_latex functions; this requires the tabulate package to be installed.

II. Basic Data Structures

pandas provides two basic data structures: Series, which stores one-dimensional values, and DataFrame, which stores two-dimensional values. Many attributes and methods are defined on these two structures.

1. Series

A Series generally consists of four parts: the sequence’s values data, its index index, its storage type dtype, and the sequence’s name name. The index may also be given a name, which is empty by default.

1
2
3
4
5

s = pd.Series(data = [100, 'a', {'dic1':5}],
              index = pd.Index(['id1', 20, 'third'], name='my_idx'),
              dtype = 'object',
              name = 'my_name')
s

my_idx
id1              100
20                 a
third    {'dic1': 5}
Name: my_name, dtype: object

[NOTE]The object type

object represents a mixed type, as illustrated above where integers, strings, and a Python dictionary are all stored together. Moreover, pandas currently treats a sequence of pure strings as an object-typed sequence by default, although it can also be stored with the string type; text sequences are discussed in Chapter 8.

[END]

You can access these attributes with the dot syntax:

1

s.values

array([100, 'a', {'dic1': 5}], dtype=object)

1

s.index

Index(['id1', 20, 'third'], dtype='object', name='my_idx')

1

s.dtype

dtype('O')

1

s.name

'my_name'

The length of a sequence can be obtained with .shape:

1

s.shape

(3,)

Indexing is one of the most important concepts in pandas and is discussed in detail in Chapter 3. To retrieve the value corresponding to a single index, use [index_item].

2. DataFrame

A DataFrame extends Series by adding column indices; a data frame can be constructed from two-dimensional data together with row and column indices:

1

df

In practice, however, data frames are more often built from a mapping of column names to data, supplemented with a row index:

4. Replacement Functions

Replacement is usually carried out on a single column, so the examples below all use Series. The replacement functions in pandas fall into three categories: mapping replacement, logical replacement, and numeric replacement. Mapping replacement includes the replace method, the str.replace method from Chapter 8, and the cat.codes method from Chapter 9; here we introduce replace.

With replace, you can specify replacements through a dictionary or by passing two lists:

1

df['Gender'].replace({'Female':0, 'Male':1}).head()

0    0
1    1
2    1
3    0
4    1
Name: Gender, dtype: int64

1

df['Gender'].replace(['Female', 'Male'], [0, 1]).head()

0    0
1    1
2    1
3    0
4    1
Name: Gender, dtype: int64

In addition, replace supports a special directional mode. Setting method to ffill replaces values with the nearest preceding value that was not replaced, whereas bfill uses the nearest following one. As the examples below show, the two produce different results:

1
2

s = pd.Series(['a', 1, 'b', 2, 1, 1, 'a'])
s.replace([1, 2], method='ffill')

0    a
1    a
2    b
3    b
4    b
5    b
6    a
dtype: object

1

s.replace([1, 2], method='bfill')

0    a
1    b
2    b
3    a
4    a
5    a
6    a
dtype: object

[WARNING]Use str.replace for regular-expression replacement

Although replace can perform regular-expression substitution, the current version still has a bug when applying it to string-typed data. If you need this functionality, use str.replace instead; the details are explained in Chapter 8.

[END]

Logical replacement comprises where and mask, which are perfectly symmetrical: where replaces the rows where the supplied condition is False, whereas mask replaces those where it is True. If no replacement value is given, missing values are used.

1

6. The apply Method

The apply method is commonly used to iterate over the rows or columns of a DataFrame. Its axis argument has the same meaning as for the statistical aggregation functions in Section 2, and the argument passed to apply is typically a function that takes a sequence as input. For example, .mean() can be written with apply as follows:

1
2
3
4
5

df_demo = df[['Height', 'Weight']]
def my_mean(x):
     res = x.mean()
     return res
df_demo.apply(my_mean)

Height    163.218033
Weight     55.015873
dtype: float64

You can likewise use a lambda expression to keep the code concise; here x refers to each successive sequence fed in from the df_demo table:

1

df_demo.apply(lambda x:x.mean())

Height    163.218033
Weight     55.015873
dtype: float64

If you set axis=1, each call passes a Series made up of a row’s elements to the function, and the result agrees with the earlier row-wise means.

1

df_demo.apply(lambda x:x.mean(), axis=1).head()

0    102.45
1    118.25
2    138.95
3     41.00
4    124.00
dtype: float64

Here is another example. The mad function returns the mean of the absolute deviations from a sequence’s mean. For the sequence 1, 3, 7, 10, the mean is 5.25, the absolute deviations are 4.25, 2.25, 1.75, 4.75, and their mean is 3.25. Let us use apply to compute the mad index for height and weight:

1

df_demo.apply(lambda x:(x-x.mean()).abs().mean())

Height     6.707229
Weight    10.391870
dtype: float64

This agrees with the result from the built-in mad function:

1

df_demo.mad()

Height     6.707229
Weight    10.391870
dtype: float64

[WARNING]Use apply with care

Because it accepts user-defined functions, apply is highly flexible — but that flexibility comes at the cost of performance. In general, handling the same task with a built-in pandas function is considerably faster than using apply, so reach for apply only when you genuinely have custom requirements.

[END]

IV. Window Objects

pandas offers three kinds of windows: the rolling window rolling, the expanding window expanding, and the exponentially weighted window ewm. Note that rolling windows sized by a date offset are discussed in Chapter 10, whereas exponentially weighted windows appear in this chapter’s exercises.

1. Rolling Window Objects

To use rolling-window functions, you must first call .rolling on a sequence to obtain a rolling object, whose most important parameter is the window size window.

1
2
3

s = pd.Series([1,2,3,4,5])
roller = s.rolling(window = 3)
roller

Rolling [window=3,center=False,axis=0]

Once you have a rolling object, you can carry out computations with the corresponding aggregation functions. Keep in mind that the window includes the element at the current row: at the fourth position, for instance, the mean is (2+3+4)/3 rather than (1+2+3)/3:

1

roller.mean()

0    NaN
1    NaN
2    2.0
3    3.0
4    4.0
dtype: float64

1

roller.sum()

0     NaN
1     NaN
2     6.0
3     9.0
4    12.0
dtype: float64

Rolling correlation and rolling covariance can be computed as follows:

1
2

s2 = pd.Series([1,2,6,16,30])
roller.cov(s2)

0     NaN
1     NaN
2     2.5
3     7.0
4    12.0
dtype: float64

1

roller.corr(s2)

0         NaN
1         NaN
2    0.944911
3    0.970725
4    0.995402
dtype: float64

You can also pass a custom function through apply; it receives the Series for the corresponding window. The mean function above, for example, can be expressed equivalently as:

1

roller.apply(lambda x:x.mean())

0    NaN
1    NaN
2    2.0
3    3.0
4    4.0
dtype: float64

shift, diff, and pct_change form a group of rolling-like functions. The value of n may be negative, indicating the analogous operation in the opposite direction.

2. Expanding Windows

An expanding window, also called a cumulative window, can be thought of as a window of variable length: at any given position it spans from the beginning of the sequence up to that position, and the aggregation functions act on these progressively growing windows. Ex2: Exponentially Weighted Windows

  1. ewm as an expanding window

Within an expanding window you can use various functions to compute cumulative historical metrics, but these built-in statistical functions typically give every element in the window the same weight. In fact, you can assign different weights to the elements; the exponentially weighted window is a special kind of expanding window that does precisely this.

The most important parameter is alpha, which determines the default window weights $w_i=(1-\alpha)^i,i\in\{0,1,...,t\}$, where $i=t$ refers to the current element and $i=0$ to the first element of the sequence.

The weight formula shows that weights decay as elements lie further from the current value. Writing the original sequence as $x$ and the updated current element as $y_t$, normalising the weighted formula gives:

$$ \begin{split}y_t &=\frac{\sum_{i=0}^{t} w_i x_{t-i}}{\sum_{i=0}^{t} w_i} \\ &=\frac{x_t + (1 - \alpha)x_{t-1} + (1 - \alpha)^2 x_{t-2} + ... + (1 - \alpha)^{t} x_{0}}{1 + (1 - \alpha) + (1 - \alpha)^2 + ... + (1 - \alpha)^{t}}\\\end{split} $$

For a Series, the exponentially smoothed sequence can be computed with an ewm object as follows:
