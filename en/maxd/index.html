The maximum distance (MaxD) algorithm is an unsupervised endmember extraction method used to identify pure endmember spectra in a hyperspectral image. This post presents the mathematical principle of the MaxD algorithm and a MATLAB implementation.

Algorithm Principle

The MaxD algorithm is based on the following key ideas:

  1. Maximum-distance criterion: Endmember spectra correspond to the sample points that lie farthest apart in feature space. This is because an endmember spectrum represents the spectrum of a pure surface material, whereas a mixed spectrum lies between endmember spectra.

  2. Sequential extraction: The algorithm extracts all endmember spectra one by one, in descending order of the distance between each endmember spectrum and the other spectra.

  3. Vector projection: When a new endmember spectrum is extracted, linear combinations of the known endmember spectra are used to construct a vector space. The new endmember spectrum is the one with the largest projection length in the complementary subspace of that space.

Given hyperspectral data with \(N\) bands, \(\mathbf{X} = \{\mathbf{x}_1, \mathbf{x}_2, \ldots, \mathbf{x}_n\}\), where \(\mathbf{x}_i \in \mathbb{R}^N\) is the \(i\)-th sample spectrum, the goal is to find \(p\) endmember spectra \(\mathbf{E} = \{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_p\}\). The steps are as follows:

  1. Initialization: Compute the norm \(\|\mathbf{x}_i\|_2\) of every sample spectrum, and select the spectrum with the largest norm as the first endmember spectrum \(\mathbf{e}_1\):
\[ \mathbf{e}_1 = \mathbf{x}_{i_1}, \quad i_1 = \arg\max_i \|\mathbf{x}_i\|_2 \]
  1. Extract the second endmember spectrum: For each remaining spectrum \(\mathbf{x}_j (j \neq i_1)\), compute its distance to the first endmember spectrum \(\mathbf{e}_1\), \(d_j = \|\mathbf{x}_j - \mathbf{e}_1\|_2\), and select the spectrum with the largest distance as the second endmember spectrum \(\mathbf{e}_2\):
\[ \mathbf{e}_2 = \mathbf{x}_{i_2}, \quad i_2 = \arg\max_j d_j \]
  1. Extract the third endmember spectrum: For each remaining spectrum \(\mathbf{x}_k (k \neq i_1, i_2)\), compute its projection length \(d_k^{(3)}\) in the complementary subspace of the plane spanned by \(\mathbf{e}_1\) and \(\mathbf{e}_2\), and select the spectrum with the largest projection length as the third endmember spectrum \(\mathbf{e}_3\):
\[ \begin{aligned} \mathbf{v}_{12} &= \mathbf{e}_2 - \mathbf{e}_1 \\ \mathbf{v}_{k} &= \mathbf{x}_k - \mathbf{e}_2 \\ \theta_k &= \arccos\left(\frac{\mathbf{v}_k^T\mathbf{v}_{12}}{\|\mathbf{v}_k\|_2\|\mathbf{v}_{12}\|_2}\right) \\ d_k^{(3)} &= \|\mathbf{v}_k\|_2 \sin\theta_k \\ \mathbf{e}_3 &= \mathbf{x}_{i_3}, \quad i_3 = \arg\max_k d_k^{(3)} \end{aligned} \]
  1. Extract the fourth endmember spectrum: For each remaining spectrum \(\mathbf{x}_l (l \neq i_1, i_2, i_3)\), compute its projection length \(d_l^{(4)}\) in the complementary subspace of the space spanned by \(\mathbf{e}_1\), \(\mathbf{e}_2\), and \(\mathbf{e}_3\), and select the spectrum with the largest projection length as the fourth endmember spectrum \(\mathbf{e}_4\):
\[ \begin{aligned} \mathbf{E}_3 &= [\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3] \\ r &= \mathrm{rank}(\mathbf{E}_3) \\ \mathbf{G} &= \mathrm{null}(\mathbf{E}_3, r) \\ \mathbf{n} &= \mathbf{G}(:,1) \\ d_l^{(4)} &= \frac{|\mathbf{v}_l^T\mathbf{n}|}{\|\mathbf{n}\|_2} \\ \mathbf{e}_4 &= \mathbf{x}_{i_4}, \quad i_4 = \arg\max_l d_l^{(4)} \end{aligned} \]
  1. Extract the remaining endmember spectra: For the \(m\)-th endmember spectrum \((m > 4)\), repeat the previous step, but use the first \(m-1\) endmember spectra to compute the complementary subspace and the projection length. The algorithm continues until no new endmember spectrum can be extracted.

Through the steps above, the MaxD algorithm extracts every endmember spectrum from the hyperspectral data one by one. Note that the algorithm is insensitive to the order of the initial spectra, but the number of endmembers \(p\) must be specified in advance.

function [Endmember]=MaxD(X,num_End)
   % Assign the input data X to mixed
   mixed = X;
   % Compute the norm of each sample spectrum
   D_O = sum(mixed.^2,2).^(1/2);
   % Find the index of the sample spectrum with the largest norm and use it as the first endmember
   [~,E_lab1]=max(D_O);
   % Store the first endmember in the first row of E
   E(1,:)=E_lab1(1,1);
   %% The second endmember
   % Compute the distance between each remaining sample spectrum and the first endmember
   D_1p = sum((mixed(E_lab1(1,1),:)-mixed).^2,2).^(1/2);
   % Find the index of the sample spectrum with the largest distance and use it as the second endmember
   [~,E_lab2] = max(D_1p);
   % Store the second endmember in the second row of E
   E(2,:)=E_lab2;
   %% The third endmember
   % Compute the vector difference between the second endmember and the first endmember
   v_12=(mixed(E_lab2,:)-mixed(E_lab1(1,1),:));
   % Compute the vector difference between each remaining sample spectrum and the second endmember
   v_2p = mixed-mixed(E_lab2,:);
   % Compute the cosine of the projection length of each remaining sample spectrum in the complementary subspace of the plane spanned by v_12
   cos = v_2p*v_12'./((sum(v_2p.^2,2).^(1/2))*(sum(v_12.^2,2).^(1/2)));
   % Compute the length of v_2p
   norm_v_p2 = sum(v_2p.^2,2).^(1/2);
   % Compute the projection angle of each remaining sample spectrum in the complementary subspace of the plane spanned by v_12
   angle = acos((cos));
   % Compute the projection length of each remaining sample spectrum in the complementary subspace of the plane spanned by v_12
   D_p_12 = norm_v_p2.*sin(angle(:));
   % Find the index of the sample spectrum with the largest projection length and use it as the third endmember
   [~,E_lab3]=max(D_p_12);
   % Store the third endmember in the third row of E
   E(3,:)=E_lab3;
   %% The forth endmember
   % Extract the matrix formed by the first three endmembers
   E_3 = mixed(E,:);
   % Compute the rank of E_3
   r =rank(E_3);
   % Compute a basis for the null space of E_3
   Gen_sol = null(E_3,r);
   % Take the first basis vector of the null space
   n = Gen_sol(:,1);
   % Compute the projection length of each remaining sample spectrum in the space spanned by n
   [~,E_lab4] = max(abs(v_2p*n)/norm(n));
   % Use the index of the sample spectrum with the largest projection length as the fourth endmember
   E(4,:) = E_lab4;
   %% The next endmember
   % For the remaining endmembers
   for i = 5:num_End
       % Extract the matrix formed by the first i-1 endmembers
       A5 = mixed(E,:);
       % Compute the rank of A5
       r5 = rank(A5);
       % Compute a basis for the null space of A5
       Gen_sol5 = null(A5,r5);
       % Take the first basis vector of the null space
       n5 = Gen_sol5(:,1);
       % Take the sample spectrum corresponding to the first endmember
       x=mixed(E(1,1),:);
       % Compute the constant term of the projection length of x in the space spanned by n5
       b5 = abs((x*n5)/norm(n5));
       % Compute the projection length of each remaining sample spectrum in the space spanned by n5
       DL5=mixed*n5+b5;
       % Compute the ratio of the projection length to the length of n5
       dis5 = (sum(abs(DL5).^2,2).^(1/2))/norm(n5);
       % Sort dis5 in descending order and obtain the sorted values together with their indices
       [rol5,cow5]=sort(dis5,'descend');
       % If the largest projection-length ratio is greater than the threshold 0.00001
       if rol5(1,1)>0.00001
           % use the corresponding sample-spectrum index as the i-th endmember
           E(i,:)=cow5(1,1);
           a = rol5(1,1);
       else
           % otherwise, exit the loop
           break
       end
   end
   % Extract the endmember spectra from mixed according to the endmember indices
   Endmember = mixed(:,E);

end

The inputs of this function are:

  • X: the hyperspectral data matrix, with one spectral sample per row

  • num_End: the number of endmembers to extract

The output is a matrix Endmember, with one extracted endmember spectrum per column.

The code follows the algorithm steps described above. Notably, when extracting the fourth and subsequent endmembers, the code computes the null space of a matrix in order to obtain a basis vector of the complementary subspace.

With this MATLAB function, the MaxD algorithm can be applied directly to real hyperspectral image analysis to recover the endmember components of the samples.

Overall, maximum distance (MaxD) endmember extraction is an important unsupervised method. Its mathematics is straightforward and it is easy to implement. It is widely used in hyperspectral remote sensing, mineral analysis, and related fields.
