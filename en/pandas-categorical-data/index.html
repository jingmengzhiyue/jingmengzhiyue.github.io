Pandas Categorical Data

1
2

import numpy as np
import pandas as pd

I. The cat Object

1. Attributes of the cat Object

pandas provides the category dtype so that users can work with categorical variables; an ordinary series can be turned into a categorical variable with the astype method.

1
2
3

df = pd.read_csv('../data/learn_pandas.csv', usecols = ['Grade', 'Name', 'Gender', 'Height', 'Weight'])
s = df.Grade.astype('category')
s.head()

0     Freshman
1     Freshman
2       Senior
3    Sophomore
4    Sophomore
Name: Grade, dtype: category
Categories (4, object): ['Freshman', 'Junior', 'Senior', 'Sophomore']

A categorical Series defines a cat object, much like the str object introduced in the previous chapter. It offers a number of attributes and methods for manipulating categories.

1

s.cat

<pandas.core.arrays.categorical.CategoricalAccessor object at 0x0000020F9B7A7108>

A concrete categorical variable has two components: the categories themselves, stored as an Index, and whether they are ordered. Both can be accessed through attributes of cat:

1

s.cat.categories

Index(['Freshman', 'Junior', 'Senior', 'Sophomore'], dtype='object')

1

s.cat.ordered

False

In addition, each series assigns a unique integer code to its categories, determined by the order in cat.categories; this attribute is accessible through codes:

1

s.cat.codes.head()

0    0
1    0
2    2
3    3
4    3
dtype: int8

2. Adding, Removing, and Modifying Categories

The categories attribute of the cat object lets you query the categories, so how do you carry out the other three operations — adding, modifying, and deleting?

[NOTE] Categories Cannot Be Modified Directly

As mentioned in Chapter 3, an Index cannot be modified with index_obj[0] = item. Since categories are stored in an Index, pandas defines several methods on the cat attribute to achieve the same end.

[END]

First, categories can be added with add_categories:

1
2

s = s.cat.add_categories('Graduate') # # Add a "Graduate" category
s.cat.categories

Index(['Freshman', 'Junior', 'Senior', 'Sophomore', 'Graduate'], dtype='object')

To remove a category use remove_categories; every element in the original series belonging to that category is then set to missing. For example, remove the freshman category:

1
2

s = s.cat.remove_categories('Freshman')
s.cat.categories

Index(['Junior', 'Senior', 'Sophomore', 'Graduate'], dtype='object')

1

s.head()

0          NaN
1          NaN
2       Senior
3    Sophomore
4    Sophomore
Name: Grade, dtype: category
Categories (4, object): ['Junior', 'Senior', 'Sophomore', 'Graduate']

You can also use set_categories to assign an entirely new set of categories; elements belonging to categories absent from the new set are set to missing.

1
2

s = s.cat.set_categories(['Sophomore','PhD']) # # The new categories are sophomore and PhD
s.cat.categories

Index(['Sophomore', 'PhD'], dtype='object')

1

s.head()

0          NaN
1          NaN
2          NaN
3    Sophomore
4    Sophomore
Name: Grade, dtype: category
Categories (2, object): ['Sophomore', 'PhD']

To drop categories that never occur in the series, use remove_unused_categories:

1
2

s = s.cat.remove_unused_categories() # # Remove the unused PhD category
s.cat.categories

Index(['Sophomore'], dtype='object')

Finally, the remaining operation among add, modify, query, and delete is modification, handled by rename_categories. Note that this method also modifies the corresponding values in the original series. For example, rename Sophomore to Second-year undergraduate:

1
2

s = s.cat.rename_categories({'Sophomore':'Second-year undergraduate'})
s.head()

0        NaN
1        NaN
2        NaN
3    Second-year undergraduate
4    Second-year undergraduate
Name: Grade, dtype: category
Categories (1, object): ['Second-year undergraduate']

II. Ordered Categoricals

1. Establishing an Order

Ordered and unordered categories can be converted into one another with as_unordered and reorder_categories. Note that the argument passed to the latter must be a list made up of the current series’ unordered categories: you may neither add new categories nor omit existing ones, and you must specify ordered=True, or the method has no effect. For example, divide the grades into relative levels and then restore the unordered state:

1
2
3

s = df.Grade.astype('category')
s = s.cat.reorder_categories(['Freshman', 'Sophomore', 'Junior', 'Senior'],ordered=True)
s.head()

0     Freshman
1     Freshman
2       Senior
3    Sophomore
4    Sophomore
Name: Grade, dtype: category
Categories (4, object): ['Freshman' < 'Sophomore' < 'Junior' < 'Senior']

1

s.cat.as_unordered().head()

0     Freshman
1     Freshman
2       Senior
3    Sophomore
4    Sophomore
Name: Grade, dtype: category
Categories (4, object): ['Freshman', 'Sophomore', 'Junior', 'Senior']

[NOTE] Categories Cannot Be Modified Directly

If you would rather not specify ordered=True, you can first convert with s.cat.as_ordered() and then use reorder_categories to make the precise relative adjustments.

[END]

2. Sorting and Comparison

In Chapter 2 we discussed the sorting of string and numeric series; now consider categorical variables. Once a column’s type has been changed to category and the appropriate ordering assigned, sort_index and sort_values work as usual. For example, sort by grade:

1
2
3

df.Grade = df.Grade.astype('category')
df.Grade = df.Grade.cat.reorder_categories(['Freshman', 'Sophomore', 'Junior', 'Senior'],ordered=True)

Once an order exists, comparisons become possible. Comparisons of categorical variables fall into two kinds. The first uses == or !=, with a scalar or a Series (or list) of the same length as the operand. The second uses the four ordering relations >,>=,<,<=; the operands are similar, but every element involved must belong to the original series’ categories and must share its index.

1
2

res1 = df.Grade == 'Sophomore'
res1.head()

res2 = df.Grade == ['PhD']*df.shape[0]

III. Interval Categories

1. Constructing Intervals with cut and qcut

Intervals are a special kind of category. In practical data analysis, interval series are usually built with cut and qcut, which bin the numeric features of the original series — replacing concrete values with interval positions.

First, the common usage of cut:

The most important parameter is bins. Given an integer n, it divides the whole array into n equal-width segments between the minimum and the maximum. Since intervals are by default left-open and right-closed, the minimum must be brought inside; pandas handles this by subtracting 0.001*(max-min) from the left endpoint of the lowest interval. Thus dividing [1,2] into two bins gives (0.999,1.5] for the first and (1.5,2] for the second. To obtain left-closed, right-open intervals instead, set right to False; the corresponding adjustment adds 0.001*(max-min) to the right endpoint of the highest interval.

1
2

s = pd.Series([1,2])
pd.cut(s, bins=2)

0    (0.999, 1.5]
1      (1.5, 2.0]
dtype: category
Categories (2, interval[float64]): [(0.999, 1.5] < (1.5, 2.0]]

1

pd.cut(s, bins=2, right=False)

0      [1.0, 1.5)
1    [1.5, 2.001)
dtype: category
Categories (2, interval[float64]): [[1.0, 1.5) < [1.5, 2.001)]

Another common use of bins is to pass a list of split points (np.infty can represent infinity):

1

pd.cut(s, bins=[-np.infty, 1.2, 1.8, 2.2, np.infty])

0    (-inf, 1.2]
1     (1.8, 2.2]
dtype: category
Categories (4, interval[float64]): [(-inf, 1.2] < (1.2, 1.8] < (1.8, 2.2] < (2.2, inf]]

Two other common parameters are labels and retbins, giving the interval names and whether to return the split points (not returned by default):

1
2
3

s = pd.Series([1,2])
res = pd.cut(s, bins=2, labels=['small', 'big'], retbins=True)
res[0]

0    small
1      big
dtype: category
Categories (2, object): ['small' < 'big']

1

res[1] # # This element is the split point

array([0.999, 1.5  , 2.   ])

In usage, qcut differs little from cut: the bins parameter simply becomes q, where q stands for quantile. When q is an integer n, the data are binned into n quantile groups; alternatively, you may pass a list of floats for the corresponding quantile boundaries.

1
2

s = df.Weight
pd.qcut(s, q=3).head()

0    (33.999, 48.0]
1      (55.0, 89.0]
2      (55.0, 89.0]
3    (33.999, 48.0]
4      (55.0, 89.0]
Name: Weight, dtype: category
Categories (3, interval[float64]): [(33.999, 48.0] < (48.0, 55.0] < (55.0, 89.0]]

1

pd.qcut(s, q=[0,0.2,0.8,1]).head()

0      (44.0, 69.4]
1      (69.4, 89.0]
2      (69.4, 89.0]
3    (33.999, 44.0]
4      (69.4, 89.0]
Name: Weight, dtype: category
Categories (3, interval[float64]): [(33.999, 44.0] < (44.0, 69.4] < (69.4, 89.0]]

2. Constructing General Intervals

A concrete interval has three elements: a left endpoint, a right endpoint, and the openness of the endpoints, where the last can be one of right, left, both, neither:

1
2

my_interval = pd.Interval(0, 1, 'right')
my_interval

Interval(0, 1, closed='right')

Its attributes include mid, length, right, left, closed,, denoting the midpoint, length, right endpoint, left endpoint, and closure state respectively.

Use in to test whether an element belongs to an interval:

1

0.5 in my_interval

True

Use overlaps to test whether two intervals intersect:

1
2

my_interval_2 = pd.Interval(0.5, 1.5, 'left')
my_interval.overlaps(my_interval_2)

True

In general, pd.IntervalIndex objects can be created in four ways — from_breaks, from_arrays, from_tuples, interval_range — each suited to different situations:

from_breaks works like cut or qcut, except that the latter two compute the split points whereas this one takes custom ones directly:

1

pd.IntervalIndex.from_breaks([1,3,6,10], closed='both')

IntervalIndex([[1, 3], [3, 6], [6, 10]],
              closed='both',
              dtype='interval[int64]')

from_arrays takes separate lists of left and right endpoints; it suits cases where intervals overlap and you know the starts and ends:

1

pd.IntervalIndex.from_arrays(left = [1,3,6,10], right = [5,4,9,11], closed = 'neither')

IntervalIndex([(1, 5), (3, 4), (6, 9), (10, 11)],
              closed='neither',
              dtype='interval[int64]')

from_tuples takes a list of tuples made up of starts and ends:

1

pd.IntervalIndex.from_tuples([(1,5),(3,4),(6,9),(10,11)], closed='neither')

IntervalIndex([(1, 5), (3, 4), (6, 9), (10, 11)],
              closed='neither',
              dtype='interval[int64]')

An equally spaced interval series is determined by a start, an end, a count, and a step. Once any three of these are fixed, the remaining one follows; the start, end, periods, freq parameters of interval_range correspond to the four quantities, so the intervals can be constructed accordingly:

1

pd.interval_range(start=1,end=5,periods=8)

IntervalIndex([(1.0, 1.5], (1.5, 2.0], (2.0, 2.5], (2.5, 3.0], (3.0, 3.5], (3.5, 4.0], (4.0, 4.5], (4.5, 5.0]],
              closed='right',
              dtype='interval[float64]')

1

pd.interval_range(end=5,periods=8,freq=0.5)

IntervalIndex([(1.0, 1.5], (1.5, 2.0], (2.0, 2.5], (2.5, 3.0], (3.0, 3.5], (3.5, 4.0], (4.0, 4.5], (4.5, 5.0]],
              closed='right',
              dtype='interval[float64]')

[Exercise]

Both interval_range here and date_range in the next chapter on time series fix three of the four elements of an arithmetic sequence and thereby determine the whole sequence. Recall how the first term, last term, number of terms, and common difference of an arithmetic progression are related, and write down the identity connecting the four parameters of interval_range.

[END]

In addition, if you call pd.IntervalIndex([...], closed=...) directly with a list of Interval objects, all the intervals are forced to the specified closed type, since pd.IntervalIndex only stores Interval objects with the same closure state.

1

my_interval

Interval(0, 1, closed='right')

1

my_interval_2

Interval(0.5, 1.5, closed='left')

1

pd.IntervalIndex([my_interval, my_interval_2], closed='left')

IntervalIndex([[0.0, 1.0), [0.5, 1.5)],
              closed='left',
              dtype='interval[float64]')

3. Interval Attributes and Methods

IntervalIndex also defines several useful attributes and methods. Moreover, to analyze the results of cut or qcut in detail, you first need to convert them to this index type:

1
2

id_interval = pd.IntervalIndex(pd.cut(s, 3))
id_interval[:3]

IntervalIndex([(33.945, 52.333], (52.333, 70.667], (70.667, 89.0]],
              closed='right',
              name='Weight',
              dtype='interval[float64]')

Like a single Interval, IntervalIndex has several common attributes: left, right, mid, length, which give the left and right endpoints, their average, and the interval length respectively.

1
2

id_demo = id_interval[:5] # # Select the first five for display
id_demo

IntervalIndex([(33.945, 52.333], (52.333, 70.667], (70.667, 89.0], (33.945, 52.333], (70.667, 89.0]],
              closed='right',
              name='Weight',
              dtype='interval[float64]')

1

id_demo.left

Float64Index([33.945, 52.333, 70.667, 33.945, 70.667], dtype='float64')

1

id_demo.right

Float64Index([52.333, 70.667, 89.0, 52.333, 89.0], dtype='float64')

1

id_demo.mid

Float64Index([43.138999999999996, 61.5, 79.8335, 43.138999999999996, 79.8335], dtype='float64')

1

id_demo.length

Float64Index([18.387999999999998, 18.334000000000003, 18.333,
              18.387999999999998, 18.333],
             dtype='float64')

IntervalIndex also has two commonly used methods, contains and overlaps, which test respectively whether each interval contains an element and whether it intersects a pd.Interval object.

1

id_demo.contains(4)

array([False, False, False, False, False])

1

id_demo.overlaps(pd.Interval(40,60))

array([ True,  True, False,  True, False])

IV. Exercises

Ex1: Counting Categories That Do Not Appear

Chapter 5 introduced crosstab, which with default parameters tabulates the frequencies of combinations of two columns:

1
2

df = pd.DataFrame({'A':['a','b','c','a'], 'B':['cat','cat','dog','cat']})
pd.crosstab(df.A, df.B)

Bcatdog
A
a20
b10
c01

In fact, some columns store categorical variables that do not necessarily contain every category. If you want these absent categories to appear in the crosstab result as well, set the dropna parameter to False:

1
2

df.B = df.B.astype('category').cat.add_categories('sheep')
pd.crosstab(df.A, df.B, dropna=False)

Bcatdogsheep
A
a200
b100
c010

Implement a my_crosstab function with a dropna parameter that reproduces the behavior above.

Ex2: The Diamonds Dataset

Here is a dataset about diamonds, in which carat, cut, clarity, price stand for carat weight, cut quality, clarity, and price respectively. A sample follows:

1
2

df = pd.read_csv('../data/diamonds.csv') 
df.head(3)

caratcutclarityprice
00.23IdealSI2326
10.21PremiumSI1326
20.23GoodVS1327
  1. Apply nunique to df.cut under the object type and the category type respectively, then compare their performance.
  2. Cut quality has five grades, from worst to best Fair, Good, Very Good, Premium, Ideal; clarity has eight, from worst to best I1, SI2, SI1, VS2, VS1, VVS2, VVS1, IF. Sort cut quality from best to worst, and for diamonds of equal cut quality sort from worst to best by clarity.
  3. Using two different methods, map the cut, clarity columns from best to worst to integers from 0 to n-1, where n denotes the number of categories.
  4. Bin the price per carat into five categories Very Low, Low, Mid, High, Very High, using quantiles (q= \[0.2, 0.4, 0.6, 0.8\]) and the split points \[1000, 3500, 5500, 18000\], then append the resulting category series to the original table in turn.
  5. In the series obtained from integer binning in question 4, do all categories appear? If any category is absent, remove it.
  6. For the series obtained from quantile binning in question 4, find the left and right endpoints and the length of the interval containing each sample.
