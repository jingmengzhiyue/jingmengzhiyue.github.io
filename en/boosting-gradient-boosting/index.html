With squared-error loss, each new tree fits the current residuals. The learning rate scales its contribution to the ensemble.

5.1 Gradient descent in function space (Friedman 2001)

Jerome H. Friedman introduced gradient boosting in his 2001 paper “Greedy Function Approximation: A Gradient Boosting Machine” (released as a technical report in 1999). He recast boosting as gradient descent in function space, another major step in the theory of boosting that lifted AdaBoost from a specific algorithm to a general framework for function optimization.

Given training data $\{(x_i, y_i)\}_{i=1}^n$, the goal is to minimize a differentiable loss:

$$\mathcal{L}(F) = \sum_{i=1}^{n} L\big(y_i, F(x_i)\big)$$

Notation: $F(x)$ is the mapping from inputs to predictions; $L(y, F)$ is the loss; $n$ is the number of training samples.

Ordinary gradient descent works in parameter space (the weights of a neural network, say). Gradient boosting makes $F(x)$ itself the object of optimization — gradient descent in function space. At iteration $m$, with current model $F_{m-1}(x)$, gradient descent says to move along the negative gradient of the loss with respect to the current prediction:

$$F_m(x) = F_{m-1}(x) - \rho_m \left. \frac{\partial L(y, F(x))}{\partial F(x)} \right|_{F=F_{m-1}}$$

Notation: $\rho_m$ is the step size (set by line search); $\frac{\partial L}{\partial F}$ is the partial derivative of the loss with respect to the predicted value.

Strictly speaking, that expression is only defined at the training points $x_1, \ldots, x_n$: treat $\left(F(x_1), \ldots, F(x_n)\right)$ as an $n$-dimensional vector and the negative gradient is the $n$-dimensional vector $\left(r_{1m}, \ldots, r_{nm}\right)$ (see Section 5.2). Such a “gradient descent” only updates predictions at the training samples; it can’t be extended to new ones.

The key insight: $F$ is an arbitrary function and the negative gradient is only known at the training points, so we can’t work in the continuous function space directly. Friedman’s move was to use a weak learner (usually a shallow decision tree) $h_m(x)$ to approximate that negative gradient direction, turning function-space gradient descent into a computable sequence of models. Each new tree is trained to fit the current model’s “negative gradient,” and then its predictions enter the model weighted by the learning rate.

5.2 Pseudo-residuals

Define the pseudo-residual of sample $i$ at iteration $m$ as

$$r_{im} = -\left[ \frac{\partial L(y_i, F(x_i))}{\partial F(x_i)} \right]_{F=F_{m-1}}$$

Notation: $r_{im}$ is the pseudo-residual of sample $i$ at round $m$; $F_{m-1}(x_i)$ is the current model’s prediction for sample $i$.

Where the name comes from

  • “Residual”: under squared loss $L(y, F) = \frac{1}{2}(y - F)^2$, the expression reduces to the ordinary residual $y_i - F_{m-1}(x_i)$, the difference between observed and predicted.
  • “Pseudo”: under a general loss it is no longer that difference but the negative gradient of the loss with respect to the prediction. Only under squared loss does it coincide with the ordinary residual, hence the “pseudo.”

The pseudo-residual points in the direction that decreases the loss fastest at the current prediction. Each new weak learner is trained to fit these pseudo-residuals, which pushes the overall model toward lower loss. Geometrically, every gradient boosting step is a move in the steepest-descent direction on the tangent plane at the current function value.

5.3 The Taylor-expansion view (first-order gradient descent)

Gradient boosting can be seen as greedy optimization of a first-order Taylor expansion of the loss.

Let the current prediction be $F_{m-1}(x_i)$ and add a weak learner $h_m(x_i)$, so the new prediction is $F_{m-1}(x_i) + h_m(x_i)$. Expand the loss to first order around $F_{m-1}$:

$$L\big(y_i, F_{m-1}(x_i) + h_m(x_i)\big) \approx L\big(y_i, F_{m-1}(x_i)\big) + h_m(x_i) \cdot \left. \frac{\partial L}{\partial F} \right|_{F_{m-1}}$$

Notation: $h_m(x_i)$ is the $m$-th weak learner’s prediction for sample $i$; $\frac{\partial L}{\partial F}$ is the partial derivative of the loss with respect to the current prediction.

Substituting the pseudo-residual:

$$L\big(y_i, F_{m-1}(x_i) + h_m(x_i)\big) \approx L\big(y_i, F_{m-1}(x_i)\big) - h_m(x_i) \cdot r_{im}$$

To make the approximated loss drop, $\sum_i h_m(x_i)\, r_{im}$ should be as large as possible, which means $h_m$’s values on the training points should point the same way as the pseudo-residual vector. But the first-order approximation only holds for small $h_m$; chasing a larger inner product alone would drive the magnitude of $h_m$ to infinity. So gradient boosting splits the problem in two: first pick the direction — the function in the weak-learner class most “parallel” to the negative gradient, which Friedman (2001) does by least squares; then set the step size — how far to move, by line search (or per-leaf optimization, see Section 5.4):

$$h_m(x) = \arg\min_{h} \sum_{i=1}^{n} \big(r_{im} - h(x_i)\big)^2$$

Notation: $h_m(x)$ is the optimal weak learner fitted to the pseudo-residuals; $r_{im}$ is the pseudo-residual of sample $i$ at round $m$.

This is exactly the core operation at each gradient boosting step: train a regression tree to fit the current model’s pseudo-residuals. Since a regression tree partitions the feature space into leaf regions and outputs a constant prediction in each, it offers a flexible and efficient way to approximate an arbitrary negative gradient direction.

5.4 A unified framework for any differentiable loss

One of Friedman’s (2001) central contributions was to extend boosting from AdaBoost’s exponential loss to a unified framework for any differentiable loss function. This is the fundamental reason gradient boosting is more general than AdaBoost.

The unified algorithm:

  1. Initialize: $F_0(x) = \arg\min_\gamma \sum_i L(y_i, \gamma)$
  2. For $m = 1, \dots, M$:
    • Compute pseudo-residuals: $r_{im} = -\left[\frac{\partial L}{\partial F}\right]_{F_{m-1}}$
    • Fit a weak learner: $h_m(x) = \arg\min_{h} \sum_i \big(r_{im} - h(x_i)\big)^2$
    • Line search for the best step: $\rho_m = \arg\min_\rho \sum_i L\big(y_i, F_{m-1}(x_i) + \rho h_m(x_i)\big)$
    • Update the model: $F_m(x) = F_{m-1}(x) + \nu \cdot \rho_m h_m(x)$
  3. Output: the final model $F_M(x)$

Notation: $\nu$ is the learning rate (shrinkage); $\rho_m$ is the optimal step from the line search; $M$ is the total number of iterations.

TreeBoost: line search per leaf. When the base learner is a regression tree with $J$ leaves, $h_m(x) = \sum_{j=1}^{J} b_{jm} \mathbb{I}(x \in R_{jm})$ is itself a combination of $J$ “basis functions.” Friedman (2001) recommends skipping a single global step $\rho_m$ and running the line search separately in each leaf region:

$$\gamma_{jm} = \arg\min_{\gamma} \sum_{x_i \in R_{jm}} L\left(y_i, F_{m-1}(x_i) + \gamma\right)$$

then updating $F_m(x) = F_{m-1}(x) + \nu \sum_{j=1}^{J} \gamma_{jm} \mathbb{I}(x \in R_{jm})$. In other words, the tree only decides how to partition the regions, while each leaf’s output is re-optimized directly against the original loss. sklearn’s GradientBoostingRegressor/Classifier and the pseudocode in Section 5.9 both take this form, and Sections 5.5 and 5.6 give the formula for $\gamma_{jm}$ under each loss.

5.5 The regression case (squared loss) in full

For regression, use the squared error (least squares) loss:

$$L(y, F) = \frac{1}{2}(y - F)^2$$

Notation: $y$ is the true target; $F$ is the model prediction; the $\frac{1}{2}$ cancels the square when differentiating, which simplifies things.

Computing the pseudo-residual

$$r_{im} = -\frac{\partial}{\partial F}\left[\frac{1}{2}(y_i - F)^2\right]_{F=F_{m-1}} = -\left[-(y_i - F)\right]_{F=F_{m-1}} = y_i - F_{m-1}(x_i)$$

The key result: under squared loss the pseudo-residual is exactly the ordinary residual (observed minus current prediction). So the intuitive reading of gradient boosting for regression is:

“Each new tree fits the residuals of the current ensemble, and its predictions join the ensemble weighted by the learning rate.”

The full regression procedure

Step 1: initialize

$$F_0(x) = \arg\min_\gamma \sum_{i=1}^{n} \frac{1}{2}(y_i - \gamma)^2 = \frac{1}{n}\sum_{i=1}^{n} y_i = \bar{y}$$

Notation: $\bar{y}$ is the mean target over the training set; $\gamma$ is the constant prediction being optimized.

Under squared loss the best initial prediction is the training mean. That’s why many gradient boosting implementations initialize $F_0$ to mean(y).

Step 2: iterate ($m = 1, \dots, M$)

  • Compute residuals: $r_{im} = y_i - F_{m-1}(x_i)$
  • Fit a regression tree: $h_m(x)$ trained on $\{(x_i, r_{im})\}$, producing leaf regions $\{R_{jm}\}_{j=1}^{J_m}$
  • For each leaf region $R_{jm}$, compute the optimal output:
$$\gamma_{jm} = \arg\min_\gamma \sum_{x_i \in R_{jm}} \frac{1}{2}\big(y_i - (F_{m-1}(x_i) + \gamma)\big)^2 = \frac{1}{\lvert R_{jm} \rvert}\sum_{x_i \in R_{jm}} r_{im}$$

Notation: $R_{jm}$ is the $j$-th leaf region of the $m$-th tree; $\lvert R_{jm} \rvert$ is the number of samples in it; $\gamma_{jm}$ is the optimal output for leaf $j$ (the mean residual in that leaf).

  • Update the model:
$$F_m(x) = F_{m-1}(x) + \nu \sum_{j=1}^{J_m} \gamma_{jm} \, \mathbb{I}(x \in R_{jm})$$

Notation: $\nu$ is the learning rate (shrinkage); $\mathbb{I}(x \in R_{jm})$ is the indicator (1 when $x$ falls in leaf $R_{jm}$, otherwise 0).

Step 3: output $F_M(x)$

Other regression losses: LAD, Huber and quantile

Squared loss is sensitive to outliers. Friedman (2001) also gave TreeBoost algorithms for several robust losses; they differ in only three places: the initial value $F_0$, the pseudo-residual $r_{im}$ (see the table in Section 5.4) and the leaf value $\gamma_{jm}$.

LossInitial $F_0$Leaf value $\gamma_{jm}$
Squared loss (LS)$\bar{y}$Mean of the in-leaf residuals $y_i - F_{m-1}(x_i)$
Absolute loss (LAD)$\operatorname{median}\{y_i\}$Median of the in-leaf residuals $y_i - F_{m-1}(x_i)$
Quantile loss ($\tau$)The $\tau$ quantile of $\{y_i\}$The $\tau$ quantile of the in-leaf residuals
Huber loss (M-TreeBoost)$\operatorname{median}\{y_i\}$Median plus a one-step correction, see below

The leaf values for LAD and quantile loss are exact: the $\gamma$ minimizing $\sum_{x_i \in R_{jm}} \lvert y_i - F_{m-1}(x_i) - \gamma \rvert$ is the median residual, and likewise for quantile loss. Note that here the tree is fitted to the pseudo-residual $\operatorname{sign}(y_i - F_{m-1}(x_i))$ (only $\pm 1$), while the leaf value is determined by the raw residuals — exactly TreeBoost’s “the tree sets the partition, the leaves are optimized separately.”

Huber loss has no closed-form leaf solution. Each round Friedman (2001) first sets the threshold $\delta_m$ to the $\alpha$ quantile of the current absolute residuals $\left\{\lvert y_i - F_{m-1}(x_i) \rvert\right\}$, then approximates the leaf value as “median plus one-step correction”: let $\tilde{r}_{jm}$ be the median of the residuals $r_{i} = y_i - F_{m-1}(x_i)$ within leaf $R_{jm}$ and $N_{jm}$ the number of samples there,

$$\gamma_{jm} = \tilde{r}_{jm} + \frac{1}{N_{jm}} \sum_{x_i \in R_{jm}} \operatorname{sign}\left(r_i - \tilde{r}_{jm}\right) \min\left(\delta_m, \lvert r_i - \tilde{r}_{jm} \rvert\right)$$

In sklearn, loss='huber' and loss='quantile' share the alpha parameter: for the former it’s which quantile of the absolute residuals to use as $\delta_m$ (default 0.9), for the latter the quantile $\tau$ to estimate. Train one quantile model with alpha=0.05 and another with alpha=0.95 and you get a 90% prediction interval.

5.6 The classification case (log loss)

For binary classification, gradient boosting uses the log loss (binomial deviance):

$$L(y, F) = -y \log\big(\sigma(F)\big) - (1-y) \log\big(1 - \sigma(F)\big)$$

Notation: $y \in \{0, 1\}$ is the class label; $\sigma(F) = \frac{1}{1 + e^{-F}}$ is the logistic sigmoid; $F(x)$ outputs log-odds, not a probability.

Computing the pseudo-residual

$$r_{im} = -\frac{\partial L}{\partial F}\bigg|_{F_{m-1}} = y_i - \sigma\big(F_{m-1}(x_i)\big) = y_i - p_i$$

Notation: $p_i = \sigma(F_{m-1}(x_i))$ is the current model’s probability that sample $i$ is positive.

Key observations:

  • Even for classification, each new tree is still a regression tree, because it fits a continuous gradient value (probability minus label) rather than a discrete class.
  • The model output $F(x)$ is log-odds; the probability comes from $\sigma(F)$.
  • When $y_i = 1$ and $p_i$ is near 0 (the model is wrong), the pseudo-residual is near 1 (the model should raise that sample’s log-odds sharply); when $p_i$ is near 1 (the model is right), it’s near 0 (no big adjustment needed).
  • The pseudo-residual lies in $(-1, 1)$, so even badly misclassified samples exert bounded “pull” on the new tree. That’s one reason log loss is more robust than exponential loss.

Initial value and leaf values (Newton step)

Initial value: the optimal constant satisfies $\sum_i \left(y_i - \sigma(\gamma)\right) = 0$, i.e. $\sigma(\gamma) = \bar{y}$:

$$F_0(x) = \log\frac{\bar{y}}{1 - \bar{y}}$$

that is, the log-odds of the positive-class rate $\bar{y}$ (which is exactly sklearn’s default initialization).

Leaf values: under log loss, $\gamma_{jm} = \arg\min_{\gamma} \sum_{x_i \in R_{jm}} L\left(y_i, F_{m-1}(x_i) + \gamma\right)$ has no closed form. Let $g_i$ and $h_i$ be the first and second derivatives of the loss with respect to $F$:

$$g_i = \frac{\partial L}{\partial F} = p_i - y_i, \qquad h_i = \frac{\partial^2 L}{\partial F^2} = p_i(1 - p_i)$$

Starting from $\gamma = 0$, take one Newton-Raphson step:

$$\gamma_{jm} \approx -\frac{\sum_{x_i \in R_{jm}} g_i}{\sum_{x_i \in R_{jm}} h_i} = \frac{\sum_{x_i \in R_{jm}} (y_i - p_i)}{\sum_{x_i \in R_{jm}} p_i (1 - p_i)}$$

This is how sklearn’s GradientBoostingClassifier computes leaf values (its source comments point to FHT 2000’s Newton step). Friedman’s original 2001 paper uses the $y \in \{-1, +1\}$ parameterization with $L = \log\left(1 + e^{-2yF}\right)$, where the pseudo-residual is $\tilde{y}_i = \frac{2y_i}{1 + e^{2y_i F_{m-1}(x_i)}}$ and the leaf value is $\gamma_{jm} = \frac{\sum \tilde{y}_i}{\sum \lvert \tilde{y}_i \rvert \left(2 - \lvert \tilde{y}_i \rvert\right)}$ — the same thing under a different parameterization.

Only one Newton step is taken here, rather than optimizing $\gamma$ to convergence in each leaf, as a compromise between cost and accuracy. XGBoost goes further and puts second-order information into the splitting criterion itself (Chapter 6).

The multiclass case ($K$ classes)

For a $K$-class problem you maintain one function $F_k(x)$ per class $k = 1, \dots, K$, using the multinomial deviance:

$$L\big(y, \{F_k\}\big) = -\sum_{k=1}^{K} \mathbb{I}(y = G_k) \log\big(p_k(x)\big)$$

Notation: $G_k$ is the $k$-th class; $\mathbb{I}(y = G_k)$ is the indicator (1 when the sample’s true class is $G_k$, otherwise 0).

Class probabilities come from the softmax:

$$p_k(x) = \frac{\exp\big(F_k(x)\big)}{\sum_{l=1}^{K} \exp\big(F_l(x)\big)}$$

Notation: $p_k(x)$ is the probability that sample $x$ belongs to class $k$; $F_k(x)$ is the score function (logit) for class $k$. Since softmax is invariant to adding the same function to all $F_k$, the $F_k$ are determined only up to a shared term; Friedman (2001) removes that degree of freedom with the constraint $\sum_{k=1}^K F_k(x) = 0$.

Pseudo-residual (for class $k$):

$$r_{ikm} = y_{ik} - p_{k, m-1}(x_i)$$

Notation: $y_{ik} = \mathbb{I}(y_i = G_k)$ is the indicator label for class $k$; $p_{k, m-1}(x_i)$ is the current model’s probability for class $k$.

The multiclass procedure

  1. Initialize: $F_{k0}(x) = 0$ in Friedman’s (2001) original; sklearn initializes with the log of each class prior $\log \bar{y}_k$ (then subtracts the mean over classes so that $\sum_k F_{k0} = 0$), where $\bar{y}_k$ is the proportion of class $k$
  2. For $m = 1, \dots, M$:
    • Compute probabilities from the current scores, $p_{k, m-1}(x_i)$ (softmax)
    • For each class $k = 1, \dots, K$:
      • Compute the pseudo-residual: $r_{ikm} = y_{ik} - p_{k, m-1}(x_i)$
      • Fit a regression tree $h_{km}(x)$ to the pseudo-residuals
      • Compute the optimal value for each leaf region (one Newton-Raphson step, Friedman 2001 Algorithm 6):
$$\gamma_{jkm} = \frac{K-1}{K} \cdot \frac{\sum_{x_i \in R_{jkm}} r_{ikm}}{\sum_{x_i \in R_{jkm}} \lvert r_{ikm} \rvert \left(1 - \lvert r_{ikm} \rvert\right)}$$

Notation: $R_{jkm}$ is the $j$-th leaf region for class $k$ at round $m$; $\gamma_{jkm}$ is that leaf’s optimal output. The factor $\frac{K-1}{K}$ comes from the constraint $\sum_k F_k = 0$.

 - Update: $F_{km}(x) = F_{k, m-1}(x) + \nu \sum_{j} \gamma_{jkm} \, \mathbb{I}(x \in R_{jkm})$
  1. Output: $\hat{y} = \arg\max_k F_{kM}(x)$, with class probabilities $p_k(x) = \operatorname{softmax}\left(F_{1M}(x), \ldots, F_{KM}(x)\right)_k$

Note: each round fits $K$ trees, so multiclass gradient boosting takes roughly $K$ times as long to train as binary.

5.7 Regularization: shrinkage, subsampling, column sampling, tree complexity

Gradient boosting is greedy and prone to overfitting. In his 2001 and 2002 papers Friedman proposed several regularization strategies that underpin modern implementations such as XGBoost and LightGBM.

Shrinkage (learning rate)

The core update:

$$F_m(x) = F_{m-1}(x) + \nu \sum_{j=1}^{J_m} \gamma_{jm} \, \mathbb{I}(x \in R_{jm}), \quad 0 < \nu \leq 1$$

Notation: $\nu$ is the learning rate (shrinkage factor), typically between $0.01$ and $0.3$; $\gamma_{jm}$ is the optimal value for each leaf of the $m$-th tree (Section 5.4).

How it works:

  • With $\nu = 1$, each tree corrects the current error by the full (in-leaf) optimal step; training loss falls fast and the model overfits more readily.
  • With $\nu < 1$, each tree contributes only part of the correction, spreading the learning over more rounds.
  • A small $\nu$ makes learning more cautious: averaging many weak learners cancels the noise of individual trees and improves generalization noticeably.

Rule of thumb: learning rate and tree count trade off:

learning_rateSuggested n_estimatorsWhen
0.1100-500Default; balances speed and quality
0.05500-2000Higher accuracy, tolerates slower training
0.012000+Chasing the best performance, with early stopping

Friedman (2001) found experimentally that a small learning rate ($\nu = 0.1$ or less) with enough trees markedly improves generalization. ESL §10.12.1 summarizes it: for a fixed number of rounds, smaller $\nu$ means higher training error, but empirically $\nu < 0.1$ usually gives better test error at the cost of a correspondingly larger $M$. So the usual practice is to set $\nu$ small and then choose $M$ with a validation set or early stopping.

Why shrinkage helps: in the limit of small steps under squared loss, “shrinkage + forward stagewise” traces a path resembling $L_1$ regularization (Lasso); ESL §16.2 discusses the connection between $\varepsilon$-forward stagewise and the Lasso, which supplies a regularization reading of shrinkage.

Subsampling (stochastic gradient boosting)

In “Stochastic Gradient Boosting,” Friedman (2002), inspired by Breiman’s bagging, proposed randomly drawing a subsample without replacement in each iteration to fit the current tree.

Changes to the algorithm:

  • In each iteration $m$, draw a fraction $f$ (usually $f = 0.5$) of the training set as $S_m$
  • Compute pseudo-residuals and fit $h_m$ using only $S_m$
  • Updates still apply to predictions for all training samples

ESL §10.12.2 notes that a sampling fraction of $1/2$ is typical, and with large $N$ it can be well below $1/2$. In sklearn, setting subsample < 1.0 enables stochastic gradient boosting; samples not drawn in a round serve as out-of-bag (OOB) samples, and oob_improvement_ records each round’s loss improvement on them, a rough guide to a sensible number of iterations.

Regularization effect:

  • Lower variance: different trees see different subsets, which increases diversity much as bagging does (sklearn’s docs note that subsample < 1.0 lowers variance and raises bias).
  • Less overfitting: the randomness stops the model from memorizing individual samples or outliers.
  • Faster training: each tree fits a smaller dataset.

Column subsampling

Borrowing from random forests, consider only a random subset of features at each split (or per tree):

  • Per split: sklearn’s max_features is the number of features considered each time a best split is sought (XGBoost’s colsample_bynode).
  • Per tree / per level: XGBoost’s colsample_bytree (once per tree) and colsample_bylevel (once per level); LightGBM’s feature_fraction (per tree).

Effect: less correlation between trees, lower variance, especially useful in high-dimensional feature spaces.

Rules of thumb: a tree of depth 3 captures at most 3-way feature interactions; too much depth memorizes noise fast. More generally, a tree with $J$ leaves can represent feature interactions up to order $J-1$. ESL §10.11 reports that $4 \leq J \leq 8$ leaves usually works well in boosting and that results aren’t very sensitive to the exact value in that range; $J = 2$ (a stump) only yields an additive model with no interaction terms.

Tuning advice

  1. Fix learning_rate = 0.1 first, and search n_estimators and max_depth with GridSearchCV or RandomizedSearchCV.

5.9 Pseudocode

Algorithm: Gradient Tree Boosting (regression)

  1. Input: training set $\{(x_i, y_i)\}_{i=1}^n$, loss $L(y, F)$, number of iterations $M$, learning rate $\nu$, tree depth $d$
  2. Output: the final model $F_M(x)$
  3. Initialize: $$F_0(x) \leftarrow \arg\min_\gamma \sum_i L(y_i, \gamma)$$ (for squared loss, $F_0(x) = \bar{y}$)
  4. For $m = 1, 2, \ldots, M$ do:
    1. Compute the pseudo-residuals: $$r_i \leftarrow -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}, \quad i = 1,\ldots,n$$
    2. Fit a regression tree: $$h_m(x) \leftarrow \operatorname{TreeFit}\left(\{(x_i, r_i)\}_{i=1}^n;\ d\right)$$ i.e. fit a depth-$d$ regression tree to $\{(x_i, r_i)\}$ under squared error, producing leaf regions $\{R_{jm}\}_{j=1}^{J_m}$
    3. For each leaf $j = 1, \ldots, J_m$ do: $$\gamma_{jm} \leftarrow \arg\min_\gamma \sum_{x_i \in R_{jm}} L(y_i, F_{m-1}(x_i) + \gamma)$$ (for squared loss: $\gamma_{jm} = \frac{1}{\lvert R_{jm} \rvert}\sum_{x_i \in R_{jm}} r_i$, the mean in-leaf residual; for other losses see Sections 5.5 and 5.6)
    4. Update the model: $$F_m(x) \leftarrow F_{m-1}(x) + \nu \sum_{j=1}^{J_m} \gamma_{jm} \, \mathbb{I}(x \in R_{jm})$$
  5. Return $F_M(x)$

import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_squared_error, accuracy_score

# ==================== sigmoid helper ====================
def sigmoid(x):
    """Numerically stable sigmoid."""
    # clip the input to keep exp from overflowing, then compute the sigmoid
    return 1 / (1 + np.exp(-np.clip(x, -250, 250)))


# ==================== Regression: Gradient Boosting Regressor ====================
class GradientBoostingRegressorScratch:
    """
    A simplified Gradient Boosting Regressor (for understanding the mechanics only).
    Uses squared loss and supports shrinkage (learning rate).
    """
    def __init__(self, n_estimators=100, learning_rate=0.1, max_depth=3):
        # total number of trees (boosting iterations)
        self.n_estimators = n_estimators
        # learning rate (shrinkage): how much of each tree's contribution to keep
        self.learning_rate = learning_rate
        # maximum depth of each regression tree
        self.max_depth = max_depth
        # all weak learners (regression trees)
        self.trees = []
        # initial prediction (the training mean under squared loss)
        self.f0 = None

    def fit(self, X, y):
        # Step 1: initialize F_0(x) = mean(y)
        # under squared loss the best constant prediction is the training mean
        self.f0 = np.mean(y)
        # fill the current prediction F with the initial value
        F = np.full_like(y, self.f0, dtype=float)

        # Step 2: run boosting, fitting one regression tree to the residuals each round
        for m in range(self.n_estimators):
            # 2a: compute pseudo-residuals (under squared loss they equal y - F)
            residuals = y - F

            # 2b: fit a regression tree to the residuals
            # the tree learns "how much the current model is still missing"
            tree = DecisionTreeRegressor(max_depth=self.max_depth, random_state=m)
            tree.fit(X, residuals)

            # 2c: get each leaf's output
            # tree.predict returns the leaf output for each sample
            # (already the optimal gamma under squared loss)
            gamma = tree.predict(X)

            # 2d: update the model (with shrinkage: each tree contributes only learning_rate of its correction)
            F += self.learning_rate * gamma

            # keep the current tree
            self.trees.append(tree)

        return self

    def predict(self, X):
        # start from the initial value f0
        F = np.full(X.shape[0], self.f0, dtype=float)

        # accumulate each tree's contribution (each scaled by learning_rate)
        for tree in self.trees:
            F += self.learning_rate * tree.predict(X)

        return F


# ==================== Classification: Gradient Boosting Classifier ====================
class GradientBoostingClassifierScratch:
    """
    A simplified binary Gradient Boosting (log loss).
    Labels must be y ∈ {0, 1}.
    """
    def __init__(self, n_estimators=100, learning_rate=0.1, max_depth=3):
        self.n_estimators = n_estimators
        self.learning_rate = learning_rate
        self.max_depth = max_depth
        self.trees = []
        # initialize log-odds = 0 → probability = sigmoid(0) = 0.5
        self.f0 = 0.0

    def fit(self, X, y):
        # y should be {0, 1}
        # initialize the model's log-odds output to 0
        F = np.full(X.shape[0], self.f0, dtype=float)

        for m in range(self.n_estimators):
            # current probability prediction p = sigmoid(F)
            p = sigmoid(F)

            # pseudo-residual = y - p (the negative gradient of log loss)
            # when y=1 and p≈0, the residual ≈1 (log-odds needs a big boost)
            # when y=1 and p≈1, the residual ≈0 (already right, no adjustment needed)
            residuals = y - p

            # train a regression tree on the pseudo-residuals
            # (note: even for classification, this is still a regression tree!)
            tree = DecisionTreeRegressor(max_depth=self.max_depth, random_state=m)
            tree.fit(X, residuals)

            # simplification: use the tree's predictions directly (mean pseudo-residual in the leaf) as gamma.
            # sklearn and others take one Newton step per leaf:
            #   gamma_j = sum(y - p) / sum(p * (1 - p))  (see Section 5.6)
            # also, F_0 = 0 here (so p = 0.5), whereas sklearn initializes with the log-odds of the positive rate.
            gamma = tree.predict(X)

            # update the log-odds
            F += self.learning_rate * gamma

            self.trees.append(tree)

        return self

    def predict_proba(self, X):
        # start from the initial log-odds
        F = np.full(X.shape[0], self.f0, dtype=float)

        # accumulate each tree's contribution
        for tree in self.trees:
            F += self.learning_rate * tree.predict(X)

        # convert log-odds to probabilities
        return sigmoid(F)

    def predict(self, X):
        # probability >= 0.5 → positive class (1), otherwise negative (0)
        return (self.predict_proba(X) >= 0.5).astype(int)

5.12 Model interpretation: relative importance and partial dependence

Along with GBM, Friedman (2001) gave two tools for interpreting tree ensembles (ESL §10.13) that are still in wide use.

Relative importance: for a single tree $T$ with $J$ leaves ($J-1$ internal nodes), the importance of feature $X_\ell$ is defined as

$$\mathcal{I}_\ell^2(T) = \sum_{t=1}^{J-1} \hat{\imath}_t^2 \, \mathbb{I}\left(v(t) = \ell\right)$$

where $v(t)$ is the splitting feature used at internal node $t$ and $\hat{\imath}_t^2$ is the squared-error reduction from that split. Averaging over $M$ trees gives the ensemble’s importance, $\mathcal{I}_\ell^2 = \frac{1}{M}\sum_{m=1}^{M} \mathcal{I}_\ell^2(T_m)$. sklearn’s feature_importances_ is this kind of impurity-decrease importance (normalized to sum to 1). Note that sklearn’s docs warn this measure favors high-cardinality features and is computed on the training set; when in doubt, compute permutation importance on a validation set with sklearn.inspection.permutation_importance.

Partial dependence: split the features into a subset of interest $X_S$ and the rest $X_C$, and define

$$\bar{f}_S(x_S) = \frac{1}{n} \sum_{i=1}^{n} F\left(x_S, x_{iC}\right)$$

that is, replace every training sample’s $X_S$ with $x_S$, leave the other features alone, and average the model’s predictions. It describes how the model output moves with $x_S$ once the other features are averaged out. In sklearn, plot it with sklearn.inspection.PartialDependenceDisplay.from_estimator. When $X_S$ and $X_C$ are strongly correlated, this substitution produces feature combinations that don’t occur in reality, so read the result with care.
