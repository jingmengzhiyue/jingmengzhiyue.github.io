Hyperspectral remote sensing is a key technique for identifying the endmember constituents within a target region and their proportions. It is widely used in land-cover classification, environmental monitoring, and related fields. Hyperspectral unmixing (HU) is the signal-processing task of analyzing hyperspectral data to identify the endmembers in an image and their corresponding abundances. Craig’s minimum-volume simplex criterion is a classical and effective method for blind unmixing: the vertices of the minimum-volume simplex that encloses the data point cloud are taken as the endmember estimates. Related algorithms are computationally inefficient, however, because they involve complicated volume calculations. HyperCSI (Hyperplane-based Craig-Simplex Identification) does not evaluate a complicated volume function. It uses a geometric theorem instead: an \(N\)-dimensional simplex can be determined by \(N\) hyperplanes (of dimension \(N-2\)). HyperCSI reconstructs Craig’s minimum-volume simplex by constructing \(N\) hyperplanes associated with it. This avoids the volume calculation and is far less expensive than algorithms based on Craig’s criterion.

Principle of the Algorithm

1. Assumptions and Notation

Let the observed data be \(\{x[1],\dots,x[L]\} \subset \mathbb{R}^M\), where each \(x[n] \in \mathbb{R}^M\) is a pixel vector in the image and contains the values of \(M\) spectral bands. The vector \(x[n]\) is assumed to be a linear combination of \(N\) endmembers \(\{a_1,\dots,a_N\}\subset \mathbb{R}^M\), and the abundance vector \(s[n] = [s_1[n],\dots,s_N[n]]^T \in \mathbb{R}^N\) satisfies the nonnegativity constraint and sums to one. That is,

\[ x[n] = \sum_{i=1}^N s_i[n] a_i + w[n], \quad \forall n \in \{1,\dots,L\} \]

where \(w[n]\) is additive noise. Let \(\alpha_i = C^\dagger (a_i-d) \in \mathbb{R}^{N-1}\) be the endmember vector after dimension reduction (DR), where \(C\in\mathbb{R}^{M \times (N-1)}\) is the matrix whose columns are the eigenvectors corresponding to the first \(N-1\) principal components of the data matrix, and \(d=\frac{1}{L}\sum_{n=1}^L x[n]\) is the data mean. The data after DR are then

\[ \tilde{x}[n] = C^\dagger (x[n] - d) = \sum_{i=1}^N s_i[n]\alpha_i \in \mathbb{R}^{N-1} \]

2. Representing Craig’s Minimum-Volume Simplex by Hyperplanes

Let Craig’s minimum-volume simplex be \(\mathcal{T} = \mathrm{conv}\{\alpha_1,\dots,\alpha_N\} \subset \mathbb{R}^{N-1}\). By the following proposition, this simplex can be determined by \(N\) associated hyperplanes \(H_1,\dots,H_N\):

Proposition 1. If \(\{\alpha_1,\dots,\alpha_N\}\subset\mathbb{R}^{N-1}\) are affinely independent (that is, \(\mathcal{T}\) is a simplex), then \(\mathcal{T}\) can be reconstructed from \(N\) hyperplanes \(\{H_1,\dots,H_N\}\) that tightly enclose \(\mathcal{T}\), where \(H_i = \text{aff}(\{\alpha_1,\dots,\alpha_N\}\backslash\{\alpha_i\})\).

Proof sketch: it is enough to show that \(\{\alpha_1,\dots,\alpha_N\}\) can be determined from \(\{H_1,\dots,H_N\}\). The proof is omitted.

The key step of HyperCSI is therefore to estimate these \(N\) hyperplanes, recover Craig’s minimum-volume simplex, and thereby obtain the endmember estimates.

3. Estimating Hyperplane Normals

Now consider how to estimate the normal \(b_i\) and the constant \(h_i\) of the \(i\)-th hyperplane \(H_i(b_i,h_i) = \{x\in\mathbb{R}^{N-1} \ \vert \ b_i^T x = h_i\}\).

By the following proposition, \(b_i\) is determined once any \(N-1\) affinely independent points on \(H_i\) have been found.

Proposition 2. Given any set of \(N-1\) affinely independent points \(\{p_1^{(i)},\dots,p_{N-1}^{(i)}\}\subset H_i\) on \(H_i\), one has (up to a positive scale factor)

\[ b_i = v_i (p_1^{(i)}, \dots, p_{N-1}^{(i)}) \]

where

\[ v_i(p_1, \dots, p_{N-1}) = (I_{N-1} - P(P^TP)^{-1}P^T)(p_j - p_i), \quad \forall j\neq i \]

and \(P = [\alpha_1 \cdots \alpha_i \cdots \alpha_j \cdots \alpha_N] - \alpha_j \cdot 1_{N-2}^T\).

Next, \(N-1\) “nearest” points \(P_i\) on \(H_i\) are sought in the original data \(X = \{\tilde{x}[1], \dots, \tilde{x}[L]\}\). The steps are as follows.

  1. First use SPA to extract from \(X\) the \(N\) purest pixels \(\{\tilde{\alpha}_1, \dots, \tilde{\alpha}_N\}\) (which may be viewed as the pixels closest to \(\alpha_1, \dots, \alpha_N\)).
  2. Compute the normal \(\tilde{b}_i\) of the hyperplane \(\tilde{H}_i = \text{aff}(\{\tilde{\alpha}_1, \dots, \tilde{\alpha}_N\}\backslash\{\tilde{\alpha}_i\})\).
  3. Partition the data set \(X\) into \(N-1\) disjoint regions \(R_1^{(i)},\dots,R_{N-1}^{(i)}\), each centered at one \(\tilde{\alpha}_j\).
  4. In each region, find the point closest to \(\tilde{H}_i\) by solving
\[ p_k^{(i)} \in \arg\max\{\tilde{b}_i^T p \mid p \in X \cap R_k^{(i)}\}, \quad \forall k\in\{1,\dots,N-1\} \]

Let the resulting point set be \(P_i = \{p_1^{(i)}, \dots, p_{N-1}^{(i)}\}\).

  1. By Proposition 2, the estimated normal of the \(i\)-th hyperplane in HyperCSI is
\[ \hat{b}_i = v_i(p_1^{(i)}, \dots, p_{N-1}^{(i)}) \]

4. Estimating the Hyperplane Inner-Product Constants

The method above yields estimated normals \(\{\hat{b}_1,\dots,\hat{b}_N\}\) of the \(N\) hyperplanes of Craig’s minimum-volume simplex. To determine these hyperplanes completely, the corresponding inner-product constants \(\hat{h}_i\) must still be estimated. Consider the following lemma.

Lemma 1.

  1. For every \(p\in X\), \(b_i^Tp \leq h_i\) (that is, all data points lie on the same side).
  2. The distance from a point \(p\in X\) to \(H_i\) is \(\text{dist}(p,H_i) = |h_i - b_i^Tp| / \|b_i\|\).
  3. If and only if \(b_i\) points from the interior of Craig’s minimum-volume simplex toward its exterior, the point corresponding to the maximum point-to-plane distance, \(\hat{p} = \arg\max\{b_i^Tp\mid p\in X\}\), is the point closest to \(H_i\).

It is then natural to take

\[ \hat{h}_i = \max\{\hat{b}_i^T p \mid p \in X\} \]

as the estimate of the corresponding inner-product constant.

In the presence of noise, noise can inflate the number of endmember types apparent in the data. The volume of Craig’s minimum-volume simplex then increases, and the estimated hyperplanes are pushed away from the data mean (the origin in the DR space). To mitigate this effect, the estimated hyperplanes are shifted inward by a suitable amount:

\[ \hat{H}_i = \{\hat{b}_i^Tx = \hat{h}_i/c\}, \quad c \geq 1 \]

where \(c\) is an inward-shift factor given by

\[ c = \max\{1, \max\{-v_{ij}/d_j \mid i\in\{1,\dots,N\}, j\in\{1,\dots,M\}\}\} / \eta \]

Here \(\eta \in (0,1]\) is a preset parameter (a typical value is \(0.9\)), \(v_{ij}\) is the \(j\)-th element of \(C(\hat{B}_{-i}^{-1}\hat{h}_{-i})\), \(d_j\) is the \(j\)-th element of the data mean \(d\), and \(\hat{B}_{-i}\) and \(\hat{h}_{-i}\) are determined by the vectors \(\{\hat{b}_j,\hat{h}_j\}_{j\neq i}\). This choice ensures that the estimated endmember signatures are nonnegative.

Finally, the endmember estimates after the inward shift are

\[ \hat{\alpha}_i = \hat{B}_{-i}^{-1}\frac{\hat{h}_{-i}}{c}, \quad \hat{a}_i = C\hat{\alpha}_i + d, \quad \forall i\in\{1,\dots,N\} \]

5. Abundance Estimation

Although abundances are usually estimated by solving a fully constrained least-squares (FCLS) problem, the geometric quantities supplied by Craig’s criterion allow the abundances to be estimated quickly by the following closed-form expression:

\[ \hat{s}_i[n] = \left(\frac{\hat{h}_i - \hat{b}_i^T\tilde{x}[n]}{\hat{h}_i - \hat{b}_i^T\hat{\alpha}_i}\right)_+, \quad \forall i\in\{1,\dots,N\}, \, \forall n\in\{1,\dots,L\} \]

where \((y)_+ = \max\{y,0\}\) enforces nonnegative abundances. When a pixel \(\tilde{x}[n]\) lies inside the simplex enclosed by the estimated endmembers, this estimate is equivalent to the solution of the FCLS problem. When a pixel lies far from the estimated simplex, some bias may appear. For high-SNR hyperspectral data, however, most pixels fall near the estimated simplex, so the fast abundance estimate above is reasonable.

Summary of the Algorithm

  • HyperCSI constructs the hyperplanes associated with Craig’s minimum-volume simplex and thereby avoids complicated volume calculations, solving Craig’s criterion efficiently.
  • It needs only \(N(N-1)\) pixels, independent of the data length, to reconstruct the \(N\) hyperplanes of Craig’s minimum-volume simplex.
  • It is proved that, with no noise and sufficiently many pixels, HyperCSI identifies the true endmembers and Craig’s minimum-volume simplex exactly.
  • Abundance estimation uses a closed form and is therefore fast.
  • The overall computational complexity is \(\mathcal{O}(N^2L)\), comparable to that of some classical pure-pixel algorithms.

In summary, HyperCSI is a novel and efficient method for solving Craig’s criterion. It avoids complicated volume calculations while retaining the strong performance of the traditional algorithms.

% References:
% C.-H. Lin, C.-Y. Chi, Y.-H. Wang, and T.-H. Chan,
% ``A fast hyperplane-based minimum-volume enclosing simplex algorithm for blind hyperspectral unmixing,"
% arXiv preprint arXiv:1510.08917, 2015.
%======================================================================
% A fast implementation of the hyperplane-based Craig-simplex identification algorithm
% [A_est, S_est, time] = HyperCSI(X,N)
%======================================================================
%  Input
%  X is an M-by-L data matrix, where M is the number of spectral bands and L is the number of pixels.
%  N is the number of endmembers.
%----------------------------------------------------------------------
%  Output
%  A_est is an M-by-N mixing matrix whose columns are the estimated endmember signatures.
%  S_est is an N-by-L source matrix whose rows are the estimated abundance maps.
%  time is the computation time (in seconds).
%========================================================================

function [A_est, S_est, time] = HyperCSI(X,N)
t0 = clock; % get the current time

%------------------------ Step 1 ------------------------
[M L ] = size(X); % get the size of X
d = mean(X,2); % compute the mean vector
U = X-d*ones(1,L); % mean centering
[eV D] = eig(U*U'); % compute eigenvalues and eigenvectors
C = eV(:,M-N+2:end); % extract the first N-1 principal components
Xd = C'*(X-d*ones(1,L)); % dimension-reduced data (Xd is (N-1)-by-L)

%------------------------ Step 2 ------------------------
alpha_tilde = SPA(Xd,L,N); % identify the purest pixels

%------------------------ Step 3 ------------------------
for i = 1:N
    bi_tilde(:,i) = compute_bi(alpha_tilde,i,N); % obtain bi_tilde
end

r = (1/2)*norm(alpha_tilde(:,1)-alpha_tilde(:,2)); % initialize the hyperball radius
for i = 1:N-1
    for j = i+1:N
        dist_ai_aj(i,j) = norm(alpha_tilde(:,i)-alpha_tilde(:,j));
        if (1/2)*dist_ai_aj(i,j) < r
            r = (1/2)*dist_ai_aj(i,j); % compute the hyperball radius
        end
    end
end
Xd_divided_idx = zeros(L,1); % initialize the label array
radius_square = r^2; % square of the radius
for k = 1:N
    [IDX_alpha_i_tilde]= find( sum(  (Xd- alpha_tilde(:,k)*ones(1,L) ).^2,1  )  < radius_square );
    Xd_divided_idx(IDX_alpha_i_tilde) = k ; % compute the hyperballs
end

%------------------------ Step 4 ------------------------
for i = 1:N
    Hi_idx = setdiff([1:N],[i]); % remove the i-th endmember
    for k = 1:1*(N-1)
        Ri_k = Xd(:,( Xd_divided_idx == Hi_idx(k) )); % select the data belonging to the k-th hyperball
        [val idx] = max(bi_tilde(:,i)'*Ri_k); % find the point with the largest projection onto bi_tilde(:,i)
        pi_k(:,k) = Ri_k(:,idx); % record these points as the N-1 affinely independent points on the hyperplane
    end
    b_hat(:,i) = compute_bi([pi_k alpha_tilde(:,i)],N,N); % compute b_hat(:,i)
    h_hat(i,1) = max(b_hat(:,i)'*Xd); % compute h_hat(i,1)
end

%------------------------ Step 5 & Step 6 ------------------------
comm_flag = 1; % comm_flag = 1 means noise is present, so the hyperplanes are moved toward the center of the data cloud
% comm_flag = 0 means there is no noise, so Step 5 is not performed (hence c = 1)

eta = 0.9; % 0.9 is an empirically good choice for endmembers in the USGS library
for i = 1:N
    bbbb = b_hat;
    ccconst = h_hat;
    bbbb(:,i) = []; % remove the i-th column
    ccconst(i) = []; % remove the i-th element
    alpha_hat(:,i) = pinv(bbbb')*ccconst; % compute alpha_hat(:,i)
end

if comm_flag == 1
    VV = C*alpha_hat; % project alpha_hat back to the original dimension
    UU = d*ones(1,N); % construct the mean vector
    closed_form_optval = max( 1 , max(max( (-VV) ./ UU)) ); % compute c'
    c = closed_form_optval/eta; % compute c
    h_hat = h_hat/c; % update h_hat
    alpha_hat = alpha_hat/c; % update alpha_hat
end
A_est = C * alpha_hat + d * ones(1,N); % endmember estimates

%------------------------ Step 7 ------------------------
% Step 7 can be removed if the user does not need abundance estimates
S_est = ( h_hat*ones(1,L)- b_hat'*Xd   ) ./ ( (  h_hat - sum( b_hat.*alpha_hat )' ) *ones(1,L) );
S_est(S_est<0) = 0; % nonnegativity constraint
% end

time = etime(clock,t0); % compute the runtime

%% subprogram 1
function [bi] = compute_bi(a0,i,N)
Hindx = setdiff([1:N],[i]); % remove the i-th endmember
A_Hindx = a0(:,Hindx); % select the other endmembers
A_tilde_i = A_Hindx(:,1:N-2)-A_Hindx(:,N-1)*ones(1,N-2); % compute A_tilde_i
bi = A_Hindx(:,N-1)-a0(:,i); % compute bi
bi = (eye(N-1) - A_tilde_i*(pinv(A_tilde_i'*A_tilde_i))*A_tilde_i')*bi; % project bi onto null(A_tilde_i)
bi = bi/norm(bi); % normalize
return;
% end

%% subprogram 2
function [alpha_tilde] = SPA(Xd,L,N)

% References:
% [1] W.-K. Ma, J. M. Bioucas-Dias, T.-H. Chan, N. Gillis, P. Gader, A. J. Plaza, A. Ambikapathi, and C.-Y. Chi, 
% ``A signal processing perspective on hyperspectral unmixing,�� 
% IEEE Signal Process. Mag., vol. 31, no. 1, pp. 67�V81, 2014.
% 
% [2] S. Arora, R. Ge, Y. Halpern, D. Mimno, A. Moitra, D. Sontag, Y. Wu, and M. Zhu, 
% ``A practical algorithm for topic modeling with provable guarantees,�� 
% arXiv preprint arXiv:1212.4777, 2012.
%======================================================================
% An implementation of the successive projection algorithm (SPA)
% [alpha_tilde] = SPA(Xd,L,N)
%======================================================================
%  Input
%  Xd is the dimension-reduced data matrix.
%  L is the number of pixels.
%  N is the number of endmembers.
%----------------------------------------------------------------------
%  Output
%  alpha_tilde is an (N-1)-by-N matrix whose columns are the purest pixels after dimension reduction.
%======================================================================
%======================================================================

%----------- Define default parameters------------------
con_tol = 1e-8; % SPA convergence tolerance
num_SPA_itr = N; % number of SPA post-processing iterations
N_max = N; % maximum number of iterations

%------------------------ SPA initialization ------------------------
A_set=[]; Xd_t = [Xd; ones(1,L)]; index = []; % initialization
[val ind] = max(sum( Xd_t.^2 )); % find the point with the largest sum of squared projections
A_set = [A_set Xd_t(:,ind)]; % add this point to A_set
index = [index ind]; % record the index
for i=2:N
    XX = (eye(N_max) - A_set * pinv(A_set)) * Xd_t; % project onto the orthogonal complement of A_set
    [val ind] = max(sum( XX.^2 )); % find the point with the largest sum of squared projections
    A_set = [A_set Xd_t(:,ind)]; % add this point to A_set
    index = [index ind]; % record the index
end
alpha_tilde = Xd(:,index); % initial estimate of the purest pixels

%------------------------ SPA post-processing ------------------------
current_vol = det( alpha_tilde(:,1:N-1) - alpha_tilde(:,N)*ones(1,N-1) ); % compute the initial volume
for jjj = 1:num_SPA_itr
    for i = 1:N
        b(:,i) = compute_bi(alpha_tilde,i,N); % compute bi
        b(:,i) = -b(:,i); % take the negative
        [const idx] = max(b(:,i)'*Xd); % find the point with the largest projection onto bi
        alpha_tilde(:,i) = Xd(:,idx); % update alpha_tilde(:,i)
    end
    new_vol = det( alpha_tilde(:,1:N-1) - alpha_tilde(:,N)*ones(1,N-1) ); % compute the new volume
    if (new_vol - current_vol)/current_vol  < con_tol
        break; % converged
    end
end
return;
% end

import numpy as np
from time import time

# Reference:
# C.-H. Lin, C.-Y. Chi, Y.-H. Wang, and T.-H. Chan,
# ``A fast hyperplane-based minimum-volume enclosing simplex algorithm for blind hyperspectral unmixing,"
# arXiv preprint arXiv:1510.08917, 2015.
#======================================================================
# A fast implementation of Hyperplane-based Craig-Simplex-Identification algorithm
# [A_est, S_est, time] = HyperCSI(X,N)
#======================================================================
#  Input
#  X is M-by-L data matrix, where M is the number of spectral bands and L is the number of pixels.
#  N is the number of endmembers.
#----------------------------------------------------------------------
#  Output
#  A_est is M-by-N mixing matrix whose columns are estimated endmember signatures.
#  S_est is N-by-L source matrix whose rows are estimated abundance maps.
#  time is the computation time (in secs).
#========================================================================

def HyperCSI(X, N):
    t0 = time()

    #------------------------ Step 1 ------------------------
    M, L = X.shape
    d = np.mean(X, axis=1, keepdims=True)
    U = X - d
    D, eV = np.linalg.eigh(U @ U.T)
    C = eV[:, M-N:M]
    Xd = C.T @ (X - d) # dimension reduced data (Xd is (N-1)-by-L)

    #------------------------ Step 2 ------------------------
    alpha_tilde = SPA(Xd, L, N) # the identified purest pixels

    #------------------------ Step 3 ------------------------
    bi_tilde = np.zeros((N-1, N))
    for i in range(N):
        bi_tilde[:, i] = compute_bi(alpha_tilde, i, N) # obtain bi_tilde

    r = 0.5 * np.linalg.norm(alpha_tilde[:, 0] - alpha_tilde[:, 1])
    for i in range(N-1):
        for j in range(i+1, N):
            dist_ai_aj = np.linalg.norm(alpha_tilde[:, i] - alpha_tilde[:, j])
            if 0.5 * dist_ai_aj < r:
                r = 0.5 * dist_ai_aj # compute radius of hyperballs

    Xd_divided_idx = np.zeros(L, dtype=int)
    radius_square = r**2
    for k in range(N):
        IDX_alpha_i_tilde = np.sum((Xd - alpha_tilde[:, k].reshape(-1, 1))**2, axis=0) < radius_square
        Xd_divided_idx[IDX_alpha_i_tilde] = k # compute the hyperballs

    #------------------------ Step 4 ------------------------
    b_hat = np.zeros((N-1, N))
    h_hat = np.zeros(N)
    for i in range(N):
        Hi_idx = [idx for idx in range(N) if idx != i]
        pi_k = np.zeros((N-1, N-1))
        for k in range(N-1):
            Ri_k = Xd[:, Xd_divided_idx == Hi_idx[k]]
            idx = np.argmax(bi_tilde[:, i].T @ Ri_k)
            pi_k[:, k] = Ri_k[:, idx] # find N-1 affinely independent points for each hyperplane
        b_hat[:, i] = compute_bi(np.hstack((pi_k, alpha_tilde[:, i].reshape(-1, 1))), N, N)
        h_hat[i] = np.max(b_hat[:, i].T @ Xd)

    #------------------------ Step 5 & Step 6 ------------------------
    comm_flag = 1
    # comm_flag = 1 in noisy case: bring hyperplanes closer to the center of data cloud
    # comm_flag = 0 when no noise: Step 5 will not be performed (and hence c = 1)

    eta = 0.9 # 0.9 is empirically good choice for endmembers in USGS library
    alpha_hat = np.zeros((N-1, N))
    for i in range(N):
        bbbb = np.delete(b_hat, i, axis=1)
        ccconst = np.delete(h_hat, i)
        alpha_hat[:, i] = np.linalg.pinv(bbbb.T) @ ccconst

    if comm_flag == 1:
        VV = C @ alpha_hat
        UU = d * np.ones((1, N))
        closed_form_optval = max(1, np.max((-VV) / UU)) # c' in Step 5
        c = closed_form_optval / eta
        h_hat = h_hat / c
        alpha_hat = alpha_hat / c

    A_est = C @ alpha_hat + d # endmemeber estimates

    #------------------------ Step 7 ------------------------
    # Step 7 can be removed if the user do not need abundance estimation
    S_est = (h_hat.reshape(1, -1) - b_hat.T @ Xd) / ((h_hat - np.sum(b_hat * alpha_hat, axis=1)).reshape(1, -1))
    S_est = np.maximum(S_est, 0)
    # end

    time_elapsed = time() - t0

    return A_est, S_est, time_elapsed

#% subprogram 1
def compute_bi(a0, i, N):
    Hindx = [idx for idx in range(N) if idx != i]
    A_Hindx = a0[:, Hindx]
    A_tilde_i = A_Hindx[:, :-1] - A_Hindx[:, -1].reshape(-1, 1)
    bi = A_Hindx[:, -1] - a0[:, i]
    A_tilde_i_pinv = np.linalg.pinv(A_tilde_i.T @ A_tilde_i)
    bi = (np.eye(N-1) - A_tilde_i @ A_tilde_i_pinv @ A_tilde_i.T) @ bi
    bi = bi / np.linalg.norm(bi)
    return bi

#% subprogram 2
def SPA(Xd, L, N):
    # Reference:
    # [1] W.-K. Ma, J. M. Bioucas-Dias, T.-H. Chan, N. Gillis, P. Gader, A. J. Plaza, A. Ambikapathi, and C.-Y. Chi,
    # ``A signal processing perspective on hyperspectral unmixing,��
    # IEEE Signal Process. Mag., vol. 31, no. 1, pp. 67�V81, 2014.
    #
    # [2] S. Arora, R. Ge, Y. Halpern, D. Mimno, A. Moitra, D. Sontag, Y. Wu, and M. Zhu,
    # ``A practical algorithm for topic modeling with provable guarantees,��
    # arXiv preprint arXiv:1212.4777, 2012.
    #======================================================================
    # An implementation of successive projection algorithm (SPA)
    # [alpha_tilde] = SPA(Xd,L,N)
    #======================================================================
    #  Input
    #  Xd is dimension-reduced (DR) data matrix.
    #  L is the number of pixels.
    #  N is the number of endmembers.
    #----------------------------------------------------------------------
    #  Output
    #  alpha_tilde is an (N-1)-by-N matrix whose columns are DR purest pixels.
    #======================================================================
    #======================================================================

    #----------- Define default parameters------------------
    con_tol = 1e-8 # the convergence tolence in SPA
    num_SPA_itr = N # number of iterations in post-processing of SPA
    N_max = N # max number of iterations

    #------------------------ initialization of SPA ------------------------
    A_set = np.zeros((N, 0))
    Xd_t = np.vstack((Xd, np.ones(L)))
    index = []
    val = np.sum(Xd_t**2, axis=0)
    ind = np.argmax(val)
    A_set = np.hstack((A_set, Xd_t[:, ind].reshape(-1, 1)))
    index.append(ind)
    for i in range(1, N):
        XX = Xd_t - A_set @ np.linalg.pinv(A_set.T @ A_set) @ A_set.T @ Xd_t
        val = np.sum(XX**2, axis=0)
        ind = np.argmax(val)
        A_set = np.hstack((A_set, Xd_t[:, ind].reshape(-1, 1)))
        index.append(ind)
    alpha_tilde = Xd[:, index]

    #------------------------ post-processing of SPA ------------------------
    current_vol = np.linalg.det(alpha_tilde[:, :-1] - alpha_tilde[:, -1].reshape(-1, 1))
    for jjj in range(num_SPA_itr):
        b = np.zeros((N-1, N))
        for i in range(N):
            b[:, i] = compute_bi(alpha_tilde, i, N)
            b[:, i] = -b[:, i]
            idx = np.argmax(b[:, i].T @ Xd)
            alpha_tilde[:, i] = Xd[:, idx]
        new_vol = np.linalg.det(alpha_tilde[:, :-1] - alpha_tilde[:, -1].reshape(-1, 1))
        if (new_vol - current_vol) / current_vol < con_tol:
            break
        current_vol = new_vol
    return alpha_tilde
