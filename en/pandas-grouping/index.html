Pandas Grouping

1
2

import numpy as np
import pandas as pd

I. Grouping Patterns and Their Objects

1. The General Pattern of Grouping

Grouping operations are ubiquitous in daily life. For example:

  • Group by gender to compute the average lifespan of the national population
  • Group by season and standardize the temperatures within each season
  • Group by class and filter out classes whose mean math score exceeds 80

From the examples above, three elements are clearly required for a grouping operation: the grouping key, the data source, and the operation along with its return value. Viewed from the other direction, once these three aspects are specified, a grouping operation is fully determined. The general form of grouping code is therefore:

1

df.groupby(grouping_key)[data_source].operation

For instance, the code for the first example should look like this:

1

df.groupby('Gender')['Longevity'].mean()

Let us return to the student fitness dataset. To compute the median height by gender, we can write:

1
2

df = pd.read_csv('../data/learn_pandas.csv')
df.groupby('Gender')['Height'].median()

Gender
Female    159.6
Male      173.4
Name: Height, dtype: float64

2. The Essence of the Grouping Key

All the examples mentioned so far group the data along a single dimension, such as gender. What if we need to group by several dimensions at once? In fact, it suffices to pass groupby a list of the corresponding column names. For example, to group by school and gender and compute the mean height, we write:

1

df.groupby(['School', 'Gender'])['Height'].mean()

Up to this point, every grouping key we have used could be fetched directly from a column by name. Suppose instead we want to group by a more elaborate rule - say, whether a student’s weight exceeds the overall mean - while still computing the mean height.

First, write out the grouping condition:

1

condition = df.Weight > df.Weight.mean()

Then pass it to groupby:

4. The Three Major Grouping Operations

Now that we have covered the basics of grouping, let us return to the three examples at the beginning and look at them with fresh eyes: the data they return come in three different shapes.

  • In the first example, each group yields a single scalar - a mean, a median, the group size size, and so on.
  • In the second example, the original series is standardized, so each group returns a Series.
  • In the third example, the result is neither a scalar nor a series; it is the rows of the entire group, hence a DataFrame.

This leads to the three major grouping operations: aggregation, transformation, and filtering, corresponding to our three examples. We will now introduce the associated agg, transform, and filter functions and how they operate.

II. Aggregation Functions

1. Built-in Aggregation Functions

Before discussing agg, we should look at the aggregation functions defined directly on the groupby object, since their speed is usually internally optimized and they should be your first choice. Functions that return a scalar include: max/min/mean/median/count/all/any/idxmax/idxmin/mad/nunique/skew/quantile/sum/std/var/sem/size/prod.

2. The agg Method

Although the groupby object offers many convenient functions, the following limitations remain:

  • Several functions cannot be applied at the same time
  • A specific aggregation function cannot be assigned to a specific column
  • Custom aggregation functions cannot be used
  • Result column names cannot be customized before aggregation

Let us see how the agg function resolves these four issues.

[a] Using Multiple Functions

To apply several aggregation functions, pass their built-in string names in a list; every string mentioned earlier is valid.

1

gb.agg(['sum', 'idxmax', 'skew'])

HeightWeight
sumidxmaxskewsumidxmaxskew
Gender
Female21014.028-0.2192536469.028-0.268482
Male8854.91930.4375353929.02-0.332393

As the result shows, the column index is now a multi-level index: the first level is the data source and the second the aggregation method used. Aggregation is applied to each column separately, giving six columns in total.

[b] Applying Specific Aggregation Functions to Specific Columns

A special correspondence between methods and columns can be expressed by passing a dictionary to agg, with column names as keys and aggregation strings (or lists of strings) as values.

1

gb.agg({'Height':['mean','max'], 'Weight':'count'})

Because a series is passed in, any method or attribute available on a series can be used inside the function, as long as the return value is a scalar. The next example returns High when a group’s mean for an indicator exceeds the overall mean of that indicator, and Low otherwise.

def my_func(s):
    res = 'High'
    if s.mean() <= df[s.name].mean():
        res = 'Low'
    return res

III. Transformation and Filtering

1. Transformation Functions and the transform Method

A transformation function returns a series of the same length. The most common built-in transformations are the cumulative functions cumcount/cumsum/cumprod/cummax/cummin; they are used in the same way as aggregation functions, except that they accumulate within each group. In addition, the groupby object defines filling and sliding-window transformations, whose general forms are discussed in Chapters 7 and 10 and are skipped here.

1

gb.cummax().head()

For a custom transformation we use the transform method. The custom function receives $\color{#FF0000}{\text{a Series from the data source}}$, just as with agg, but its final result is a DataFrame whose row and column indexes match those of the data source.

2. Group Indexing and Filtering

The previous chapter introduced indexing, so how does indexing differ from filtering?

Filtering, in the context of grouping, operates on groups, whereas indexing operates on rows. The return values discussed in Chapter 2 - whether a list of booleans, a list of elements, or a list of positions - are all essentially row selections: a row is kept if it meets the condition and discarded otherwise.

Group filtering generalizes row filtering: a group is kept when the statistic computed over all of its rows returns True, and discarded when it returns False. Finally, the rows of every surviving group are concatenated into a single DataFrame and returned.

The groupby object defines a filter method for this purpose. Its custom function receives the DataFrame formed by the data source itself - in the groupby object defined above, that is df[['Height', 'Weight']]. Consequently, all table methods and attributes are available inside the function, and it only needs to return a boolean value.

For example, to keep every group with more than 100 rows from the original table:

1

gb.filter(lambda x: x.shape[0] > 100).head()

HeightWeight

IV. Cross-Column Grouping

1. Introducing apply

The previous sections covered the three major grouping operations, yet there is another common scenario that none of them can handle. Suppose body mass index is defined as follows:

$${\rm BMI} = {\rm\frac{Weight}{Height^2}}$$

Here weight and height are measured in kilograms and meters, respectively, and we need to compute the group-wise mean of BMI.

First, this is clearly not a filtering operation, so filter will not do. Second, the mean is a scalar rather than a series, ruling out transform. Finally, agg might appear to work, but aggregation functions process one column at a time and cannot $\color{#FF0000}{\text{process several columns at once}}$. This is where apply comes in.

2. Using apply

By design, apply passes the same arguments to its custom function as filter does; the difference is that filter only allows a boolean result. Here is how the calculation above can be solved:

1
2
3
4
5
6

def BMI(x):
    Height = x['Height']/100
    Weight = x['Weight']
    BMI_value = Weight/Height**2
    return BMI_value.mean()
gb.apply(BMI)

Gender
Female    18.860930
Male      24.318654
dtype: float64

Finally, it must be emphasized that the flexibility of apply comes at the cost of some performance. Unless cross-column processing is genuinely needed, prefer one of the specially designed groupby methods, or you will pay a substantial speed penalty. Likewise, when using aggregation and transformation functions, favor the built-in implementations: they are highly optimized and are generally faster than equivalent custom functions.

Ex1: The Car Dataset

We have a dataset of cars in which Brand, Disp., HP stand for the brand, engine displacement, and engine output, respectively.

2

df = pd.read_csv('../data/car.csv')
df.head(3)

  1. First filter out cars whose Country appears no more than twice in the whole dataset, keeping only those from countries with more than two cars. Then group by Country and compute the mean price, the coefficient of variation of price, and the number of cars per Country. The coefficient of variation is the standard deviation divided by the mean; rename it CoV in the result.
