The N-FINDR algorithm extracts endmember signatures from a hyperspectral data cube. Its core idea is to search the data set for the simplex of maximum volume, whose vertices are the desired endmembers. The mathematical principle and the concrete steps are as follows.

Mathematical Principle

Consider an \(M \times N \times C\)-dimensional hyperspectral data cube \(\mathbf{X}\). From it we need to find \(p\) endmember signatures \(\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_p\). The matrix formed by these signature vectors is written \(\mathbf{E} = [\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_p]^T \in \mathbb{R}^{C \times p}\).

Under the linear mixing model, each pixel \(\mathbf{x}_i\) in the data cube \(\mathbf{X}\) can be expressed as a linear combination of the endmember signatures:

\[ \mathbf{x}_i = \sum_{j=1}^p a_{ij} \mathbf{e}_j + \mathbf{n}_i \]

where \(a_{ij}\) is the corresponding abundance fraction, subject to the constraints \(\sum_{j=1}^p a_{ij} = 1\) and \(a_{ij} \geq 0\), and \(\mathbf{n}_i\) is an additive noise term.

The goal of N-FINDR is to find a set of endmember signatures \(\mathbf{E}\) such that the \(p\)-dimensional simplex formed by these signature vectors has maximum volume. The volume of that simplex can be expressed as the absolute value of the determinant of the endmember matrix \(\mathbf{E}\):

\[ \mathrm{vol}(\mathbf{E}) = |\det(\mathbf{E})| \]

The algorithm iteratively updates the endmember matrix \(\mathbf{E}\) until it finds the solution that maximizes the determinant above.

Algorithm Steps

  1. Initialization: Randomly select \(p\) pixels from the data cube as the initial endmember signature vectors, form the initial endmember matrix \(\mathbf{E}^{(0)}\), and compute the absolute value of its determinant, \(\mathrm{vol}(\mathbf{E}^{(0)})\).

  2. Iteration:

    • For each endmember signature vector \(\mathbf{e}_i^{(t)}\), replace it with another pixel \(\mathbf{x}_j\) from the data cube to form a new endmember matrix \(\mathbf{E}_{ij}^{(t+1)}\).

    • Compute \(\mathrm{vol}(\mathbf{E}_{ij}^{(t+1)})\). If it is greater than \(\mathrm{vol}(\mathbf{E}^{(t)})\), update \(\mathbf{E}^{(t+1)} = \mathbf{E}_{ij}^{(t+1)}\).

    • Repeat the steps above until the volume can no longer be increased.

  3. Output: The final endmember matrix \(\mathbf{E}\) is the solution.

function endmemSig = nfindr(cube, num, option)
% NFINDR extracts endmember signatures by finding a simplex on the data cube
%   ENDMEMSIG = NFINDR(CUBE, NUM) estimates endmember signatures by finding the volume of a simplex on the dimensionality-reduced data
%   NUM is the number of endmember signatures present in CUBE
%   CUBE is an M-by-N-by-C numeric array containing hyperspectral data, or a hyperspectral cube object
%   M and N are the number of rows and columns of the hyperspectral cube, respectively
%   C is the number of bands in the hyperspectral cube
%   NUM is a positive integer greater than 1
%   The output ENDMEMSIG is a C-by-NUM numeric matrix that provides the endmember signatures

%   ENDMEMSIG = NFINDR(___, Name, Value) estimates endmember signatures by finding the maximum-volume simplex on the dimensionality-reduced data, using the selected name-value pairs

%   'NumIterations'  Number of times the algorithm is run. If it has not converged, the default value is 3*NUM

%   'ReductionMethod' - Method used to perform dimensionality reduction. The choices are:
%
%       'PCA'  Based on the directions of greatest data variation, principal component analysis (PCA) transforms a large amount of data into a smaller set
%              while retaining most of the information
%
%       'MNF'  Based on the noise fraction, the maximum noise fraction (MNF) transform converts a large amount of data into a smaller set
%              while retaining most of the information. MNF orders the components according to image quality
%              The default method is MNF

%   Notes
%   -----
%   1) The NFINDR algorithm uses the default random seed to generate random unit vectors
%
%   2) For larger data sets, the NFINDR algorithm is computationally expensive

%   Class Support
%   -------------
%   The input array CUBE must belong to one of the following classes: uint8, uint16, uint32, int8, int16, int32, single, double, uint64, int64, or a hypercube object
%   It must be real and nonsparse
%   NUM and NUMITER are positive integer scalars
%   The output ENDMEMSIG is a C-by-NUM numeric matrix of the same class as the input cube

%   References
%   ---------
%   M.E. Winter, "N-FINDR: an algorithm for fast autonomous spectral
%   end-member determination in hyperspectral data", Proc. SPIE 3753,
%   Imaging Spectrometry V, 1999.

%   Example 1: Find endmember signatures
%   -----------
%   % Load the Indian Pines data set
%   cube = load('indian_pines.mat');
%
%   % Estimate the number of endmembers
%   num = countEndmembersHFC(cube.indian_pines);
% 
%   % Estimate and visualize the endmember signatures
%   endmemSig = nfindr(cube.indian_pines, num);
%   plot(endmemSig);
%   xlabel('Band index')
%   ylabel('Signatures')
%   title('Endmembers')

%   Example 2: Find endmember signatures using the 'PCA' dimensionality-reduction method
%   -----------
%   % Read the hyperspectral cube
%   obj = hypercube('indian_pines.hdr');
%
%   % Estimate the number of endmembers
%   num = countEndmembersHFC(obj);
%
%   % Estimate endmember signatures with the NFINDR method
%   endmemSig = nfindr(obj, num, 'ReductionMethod', 'pca');
%   plot(endmemSig);
%   xlabel('Band index')
%   ylabel('Signatures')
%   title('Endmembers')
%
%   See also ppi, fippi, hypercube, countEndmembersHFC.
%
%   Copyright 2020-2021 The MathWorks, Inc.

arguments
    cube {mustBeA(cube,'hypercube')} % Require cube to be a hypercube object
     num (1,1) {mustBeNumeric, mustBeNonNan, mustBeFinite, mustBeNonsparse, ...
        mustBeNonempty, mustBeReal, mustBeInteger, mustBePositive, ...
        mustBeLessSize(num, cube)} % Require num to be a positive integer smaller than the number of bands
    option.NumIterations (1,1) {mustBeNumeric, mustBeNonNan, mustBeFinite, ...
        mustBeNonsparse, mustBeNonempty, mustBeReal, mustBeInteger,...
        mustBePositive} = 3*num % The default number of iterations is 3*num
    option.ReductionMethod (1,1) string ...
        {validatestring(option.ReductionMethod,{'MNF', 'PCA'})} = "MNF"  % The default dimensionality-reduction method is MNF
end

% Used for compiler testing
if isdeployed
    rootDir = ctfroot;
else
    rootDir = matlabroot;
end
% Register resources/hyperspectral
matlab.internal.msgcat.setAdditionalResourceLocation(rootDir);

% Input parsing
if isobject(cube)
    cube = cube.DataCube; % If cube is an object, extract the data cube
end

maxItr = option.NumIterations; % Maximum number of iterations
method = validatestring(option.ReductionMethod, {'MNF', 'PCA'}); % Dimensionality-reduction method

% Cube dimensions
[rows, cols, channels] = size(cube);
numOfSamples = rows*cols; % Number of samples

% Reshape the original data cube
originalCube = reshape(cube, numOfSamples, channels);

if isinteger(cube)
    cube = single(cube); % Convert integer types to single
    num = single(num);
end

if strcmpi(method, 'PCA')
    % Perform principal component analysis (PCA) on the hyperspectral cube
    cube = hyperpca(cube, num-1);
    
else
    % Use the maximum noise fraction (MNF) transform to reduce the computational cost
    cube = hypermnf(cube, num-1);
end

% Reshape the dimensionality-reduced cube
cube = reshape(cube, [numOfSamples num-1]);

% Initialize the matrix and set the first row to 1. Each column vector contains an endmember spectrum
signatures = zeros(num);
signatures(1,:) = 1;

% Generate random samples in the range from 1 to numOfSamples
prevS = rng('default');
randSamplesInd = randi([1 numOfSamples], 1, num);

% Restore the random-number state on cleanup
cleanup = onCleanup(@() rng(prevS));
% Select random pixels and set them as endmembers
signatures(2:num, :) = cube(randSamplesInd, :)';

% For this algorithm, division by factorial(p-1) is invariant, so it is skipped
actualVolume = abs(det(signatures));

% Initialize the iteration count
itr = 1;

% Initialize the volumes v1 and v2
initVol = -itr;
maxVol = actualVolume;

% Compute the volume for every pixel. If replacing a pixel increases the volume, treat the replacement pixel as an endmember
% Repeat this process until no further endmember replacements are made
while maxVol > initVol
    for sigCount=1:num
         
         % Find the simplex that defines the volume
         [randSamplesInd, actualVolume, signatures] = findSimplex(signatures, cube, ...
             randSamplesInd, actualVolume, numOfSamples, num, sigCount); 
    end
    
    % Break if the maximum number of iterations is reached
    if itr == maxItr
        break;
    end
    
    % Update the iteration count, v1, and v2
    itr = itr+1;
    initVol = maxVol;
    maxVol = actualVolume;
end

% Extract the endmember signatures from the volume according to the sample indices
endmemSig = originalCube(randSamplesInd, :)';
end

function [randSamplesInd, actualVolume, signatures] = findSimplex(signatures, reducedCube, ...
    randSamplesInd, actualVolume, numOfSamples, num, sigCount)
for sampleCount=1:numOfSamples
    
    % Check each sample after dimensionality reduction
    signatures(2:num, sigCount) = reducedCube(sampleCount, :);

    % The volume of the simplex formed by the estimated endmembers is proportional to the determinant of the signature matrix
    volume = abs(det(signatures));
    if volume > actualVolume
        actualVolume = volume;
        randSamplesInd(sigCount) = sampleCount;
    end
end

% Update the endmember signatures with the latest sample
signatures(2:num, sigCount) = reducedCube(randSamplesInd(sigCount), :);

end

function mustBeA(hypercube,classIn)

if isobject(hypercube)
    validateattributes(hypercube,{classIn},{'nonempty'},'nfindr','hypercube');
    cube = hypercube.DataCube;
else
    cube = hypercube;
end

validateattributes(cube, ...
    {'numeric'}, {'nonsparse', 'nonempty', 'real','nonnan', 'finite', ...
    'ndims',3}, mfilename, 'hypercube', 1);

end

% Validate that numComponents is smaller than the number of bands
function mustBeLessSize(a, b)
if isobject(b)
    cube = b.DataCube;
else
    cube = b;
end
sz = size(cube);
validateattributes(a, {'numeric'},...
    {'>', 1, '<=',sz(3), 'scalar'},mfilename, 'num',2);

if (a >= sz(1)*sz(2))
    error(message('hyperspectral:hyperpca:notGreaterEqual'));    
end
end

The advantage of this algorithm is that the idea is clear: it can effectively extract the endmember signatures corresponding to the maximum-volume cluster. Its disadvantage is that the computation is heavy, and large data sets take a long time. In practice, the data are therefore usually reduced first with PCA, MNF, or a similar method, and N-FINDR is then run on the reduced data to cut the computational cost.

Overall, N-FINDR extracts endmembers from the data by maximizing the volume of the simplex formed by the endmember signature vectors. It is a classic unsupervised endmember-extraction algorithm.
