I. Counting and Deleting Missing Values

2. Deleting Missing Information

Data processing often calls for dropping row samples or column features according to the size, proportion, or other characteristics of their missing values. pandas provides the dropna function for this task.

The main parameters of dropna are the axis direction axis (default 0, meaning rows are removed), the removal mode how, the threshold thresh for the number of non-missing values (a dimension is dropped when $\color{red}{\text{the number of non-missing values}}$ fails to reach this count), and the optional deletion subset subset. For how, the choices are any and all.

For example, drop the rows where at least one of height and weight is missing:

1
2

res = df.dropna(how = 'any', subset = ['Height', 'Weight'])
res.shape

(174, 6)

For example, drop the columns with more than 15 missing values:

1
2

res = df.dropna(1, thresh=df.shape[0]-15) # # The Height column is dropped
res.head()

II. Filling Missing Values and Interpolation

1. Filling with fillna

Three parameters of fillna see frequent use: value, method, limit. Here value is the fill value, either a scalar or a dictionary mapping indexes to elements; method is the fill strategy, with ffill filling forward from the preceding element and bfill filling backward from the following one; and limit gives the maximum number of times consecutive missing values are filled.

Let us construct a simple Series to illustrate the usage:

1
2

s = pd.Series([np.nan, 1, np.nan, np.nan, 2, np.nan], list('aaabcd'))
s

a    NaN
a    1.0
a    NaN
b    NaN
c    2.0
d    NaN
dtype: float64

1

s.fillna(method='ffill') # # Forward-fill from the preceding value

a    NaN
a    1.0
a    1.0
b    1.0
c    2.0
d    2.0
dtype: float64

1

s.fillna(method='ffill', limit=1) # # A run of missing values is filled at most once

a    NaN
a    1.0
a    1.0
b    NaN
c    2.0
d    2.0
dtype: float64

1

s.fillna(s.mean()) # # value is a scalar

a    1.5
a    1.0
a    1.5
b    1.5
c    2.0
d    1.5
dtype: float64

1

s.fillna({'a': 100, 'd': 200}) # # Fill values through an index mapping

a    100.0
a      1.0
a    100.0
b      NaN
c      2.0
d    200.0

Sometimes a more sensible fill requires grouping first. For example, fill missing heights with the mean height within each grade:

2. Interpolation Functions

The documentation for the interpolate function lists many interpolation methods, including a large number from Scipy. Because many of them rely on fairly involved mathematics, only three common and simple cases are discussed here: linear interpolation, nearest-neighbour interpolation, and index interpolation.

For interpolate, besides the method itself (which defaults to linear), two parameters resemble those of fillna: limit_direction governs the direction, while limit caps the number of consecutive missing values to interpolate. By default the direction is forward, analogous to ffill in fillna; to restrict interpolation backward or in both directions, pass backward or both.

1
2

s = pd.Series([np.nan, np.nan, 1, np.nan, np.nan, np.nan, 2, np.nan, np.nan])
s.values

array([nan, nan,  1., nan, nan, nan,  2., nan, nan])

For example, under the default linear method, carry out backward and two-way limited interpolation, capping the run length at 1:

1
2

res = s.interpolate(limit_direction='backward', limit=1)
res.values

array([ nan, 1.  , 1.  ,  nan,  nan, 1.75, 2.  ,  nan,  nan])

1
2

res = s.interpolate(limit_direction='both', limit=1)
res.values

array([ nan, 1.  , 1.  , 1.25,  nan, 1.75, 2.  , 2.  ,  nan])

The second common approach is nearest-neighbour imputation, in which a missing element takes the value of the nearest non-missing element:

1

s.interpolate('nearest').values

array([nan, nan,  1.,  1.,  1.,  2.,  2., nan, nan])

Finally, index interpolation performs linear interpolation according to the size of the index. To demonstrate it, construct an index with unequal spacing:

1
2

s = pd.Series([0,np.nan,10],index=[0,1,10])
s

0      0.0
1      NaN
10    10.0
dtype: float64

1

s.interpolate() # # Default linear interpolation, equal to the midpoint

0      0.0
1      5.0
10    10.0
dtype: float64

1

s.interpolate(method='index') # # Index-aware interpolation based on index values

0      0.0
1      1.0
10    10.0
dtype: float64

This method also works with timestamp indexes. Other topics concerning time series are discussed in Chapter 10; here is a simple example:

1
2

s = pd.Series([0,np.nan,10], index=pd.to_datetime(['20200101', '20200102', '20200111']))
s

2020-01-01     0.0
2020-01-02     NaN
2020-01-11    10.0
dtype: float64

1

s.interpolate()

2020-01-01     0.0
2020-01-02     5.0
2020-01-11    10.0

1

s.interpolate(method='index')

2020-01-02     1.0
2020-01-11    10.0

[NOTE] A note on polynomial and spline interpolation

In interpolate, choosing the polynomial method calls scipy.interpolate.interp1d(*,*,kind=order) internally, which in turn calls make_interp_spline; it is therefore spline interpolation rather than a polynomial fit in the spirit of numpy’s polyfit. Choosing spline, by contrast, makes pandas call scipy.interpolate.UnivariateSpline instead of ordinary spline interpolation. The documentation on this part is rather muddled, and the design of these options is questionable. Whenever you use either method, take care to pick the interpolation that truly fits your needs.

[END]

III. Nullable Types

1. Missing Markers and Their Drawbacks

In python, a missing value is denoted by None, which equals only itself and is unequal to every other element:

1

None == None

True

1

None == False

False

1

None == []

False

1

None == ''

False

In numpy, missing values are represented by np.nan, which is unequal not only to any other element but also to itself:

1

np.nan == np.nan

False

1

np.nan == None

False

1

np.nan == False

False

It is worth noting that although comparing the elements of a series or table containing missing values returns False at the positions of np.nan, the equals function skips positions where both sides are missing and returns True outright:

1
2
3
4

s1 = pd.Series([1, np.nan])
s2 = pd.Series([1, 2])
s3 = pd.Series([1, np.nan])
s1 == 1

0     True
1    False
dtype: bool

1

s1.equals(s2)

False

1

s1.equals(s3)

True

For time-series objects, pandas uses pd.NaT to denote missing values; it serves the same purpose as np.nan (time-series objects and their construction are discussed in Chapter 10):

1

pd.to_timedelta(['30s', np.nan]) # # NaT inside Timedelta

TimedeltaIndex(['0 days 00:00:30', NaT], dtype='timedelta64[ns]', freq=None)

1

pd.to_datetime(['20200101', np.nan]) # # NaT inside Datetime

DatetimeIndex(['2020-01-01', 'NaT'], dtype='datetime64[ns]', freq=None)

So why introduce pd.NaT for missing values in time objects, and what would be wrong with storing them as np.nan? In pandas you will encounter objects of type object, a catch-all type: if a Series holds elements of several different types, its dtype becomes object. For example, a list holding both integers and strings:

1

pd.Series([1, 'two'])

0      1
1    two
dtype: object

The root of the NaT problem is that np.nan is itself a floating-point type. If floats and time types were stored together without a new built-in missing type, the result would be an ambiguous object type — plainly undesirable.

1

type(np.nan)

float

Moreover, owing to the floating-point nature of np.nan, a missing value in an integer Series turns its dtype into float64, while a missing value in a boolean Series turns it into object rather than bool:

1

pd.Series([1, np.nan]).dtype

dtype('float64')

1

pd.Series([True, False, np.nan]).dtype

dtype('O')

For all these reasons, starting with version 1.0.0, pandas set out to design a new missing type, pd.NA, along with three Nullable Series types: Int, boolean, and string.

2. Properties of Nullable Types

Taken literally, Nullable means capable of holding nulls — the Series type is, as it were, unfazed by missing values. For example, a missing value stored in any of the three Nullable types above is converted to the built-in pd.NA:

1

pd.Series([np.nan, 1], dtype = 'Int64') # # The "I" is uppercase

0    <NA>
1       1
dtype: Int64

1

pd.Series([np.nan, True], dtype = 'boolean')

0    <NA>
1    True
dtype: boolean

1

pd.Series([np.nan, 'my_str'], dtype = 'string')

0      <NA>
1    my_str
dtype: string

In an Int Series, the result of an operation is kept as a Nullable type whenever possible:

1

pd.Series([np.nan, 0], dtype = 'Int64') + 1

0    <NA>
1       1
dtype: Int64

1

pd.Series([np.nan, 0], dtype = 'Int64') == 0

0    <NA>
1    True
dtype: boolean

1

pd.Series([np.nan, 0], dtype = 'Int64') * 0.5 # # Floating point only

0    NaN
1    0.0
dtype: float64

For a boolean Series, behaviour differs from a bool Series in two main respects.

First, a boolean list containing missing values cannot serve as an indexer, whereas boolean treats missing values as False:

1
2
3
4
5

s = pd.Series(['a', 'b'])
s_bool = pd.Series([True, np.nan])
s_boolean = pd.Series([True, np.nan]).astype('boolean')
# s[s_bool] raises an error
s[s_boolean]

0    a
dtype: object

Second, in logical operations bool always returns False at a missing position, whereas boolean returns a value depending on whether the logic can determine a unique result. What does “determine a unique result” mean? A simple example: in True | pd.NA the result is necessarily True whatever the missing value happens to be; in False | pd.NA the outcome varies with the value of the missing element, so pd.NA is returned; in False & pd.NA the result is necessarily False regardless of the missing value.

1

s_boolean & True

0    True
1    <NA>
dtype: boolean

1

s_boolean | True

0    True
1    True
dtype: boolean

1

~s_boolean # # Negation still cannot determine a missing value uniquely

0    False
1     <NA>
dtype: boolean

The specific properties of the string type are discussed in the next chapter on textual data.

In practical data work, after reading in a dataset you can convert it to Nullable types up front with convert_dtypes:

1
2
3

df = pd.read_csv('../data/learn_pandas.csv')
df = df.convert_dtypes()
df.dtypes

Height         float64

3. Computation and Grouping of Missing Data

When sum, prod are called and addition and multiplication are involved, missing data is treated as 0 and 1 respectively, leaving the original result unchanged:

1
2

s = pd.Series([2,3,np.nan,4,5])
s.sum()

14.0

1

s.prod()

120.0

Cumulative functions automatically skip the positions occupied by missing values:

1

s.cumsum()

0     2.0
1     5.0
2     NaN
3     9.0
4    14.0
dtype: float64

For scalar operations, every result is missing (and pd.NA behaves in the same way) except np.nan ** 0 and 1 ** np.nan, which produce definite values. Furthermore, np.nan always returns False in comparisons, whereas pd.NA returns pd.NA:

1

pd.NA ** 0

1

1.0

1

1 ** pd.NA

In fact, the presence or absence of a missing value is itself sometimes a feature, and in some settings it may be related to the sign of the label. In statistics, a chi-square test can tell us whether the occurrence of missingness and the sign of the label are associated. Four cases can be distinguished: a positive with the feature missing, a negative with the feature missing, a positive with the feature present, and a negative with the feature present; let their sample counts be $n_{11}, n_{10}, n_{01}, n_{00}$, respectively. If the two were independent, the theoretical count of positives among the missing-feature cases should be close to the total number of missing-feature cases $\times$ the overall proportion of positives, namely:

$$E_{11} = n_{11} \approx (n_{11}+n_{10})\times\frac{n_{11}+n_{01}}{n_{11}+n_{10}+n_{01}+n_{00}} = F_{11}$$

The other three cases follow the same reasoning. Write the actual and theoretical values as $E_{ij}, F_{ij}$, respectively; we would then like the statistic below to be as small as possible, since a small value means the observed counts lie close to those expected under independence:

$$S = \sum_{i\in \{0,1\}}\sum_{j\in \{0,1\}} \frac{(E_{ij}-F_{ij})^2}{F_{ij}}$$

It can be shown that this statistic approximately follows a chi-square distribution with $1$ degree of freedom, i.e. $S\overset{\cdot}{\sim} \chi^2(1)$. The correlation can therefore be judged by computing $P(\chi^2(1)>S)$: when this probability falls below $0.05$, the missingness is regarded as related to the sign of the label — in other words, the theoretical value under independence differs markedly from the observed one.

The probability just mentioned is, for a $2\times2$ contingency table test in statistics, the $p$-value; it is available through scipy.stats.chi2.sf(S, 1). Using the material above, test the X_1, X_2 columns separately.

Ex2: Solving a Classification Problem with a Regression Model

KNN is a supervised learning model that handles both regression and classification. For a categorical variable, a KNN classifier can impute its missing values: measure the distance between the features of the missing sample and those of all the other samples; once n_neighbors=n is given, find the most frequent class among the $n$ nearest samples and assign it as the predicted class for the missing sample.
