Pandas Indexing

I. Indexers

1. Column Indexing in a Table

Column indexing is the most common form of indexing and is typically done with []. Using [column name] extracts the corresponding column from a DataFrame and returns a Series—for example, selecting the name column:

1
2

df = pd.read_csv('../data/learn_pandas.csv', usecols = ['School', 'Grade', 'Name', 'Gender', 'Weight', 'Transfer'])
df['Name'].head()

0      Gaopeng Yang
1    Changqiang You
2           Mei Sun
3      Xiaojuan Sun
4       Gaojuan You
Name: Name, dtype: object

To fetch multiple columns, pass a [list of column names]; the result is a DataFrame. Here we extract the gender and name columns:

1

df[['Gender', 'Name']].head()

GenderName
0FemaleGaopeng Yang
1MaleChangqiang You
2MaleMei Sun
3FemaleXiaojuan Sun
4MaleGaojuan You

In addition, when selecting a single column whose name contains no spaces, you can use .column_name, which is equivalent to [column name]:

1

df.Name.head()

0      Gaopeng Yang
1    Changqiang You
2           Mei Sun
3      Xiaojuan Sun

Name: Name, dtype: object

2. Row Indexing of a Series

[a] Series with string indices

To retrieve the element corresponding to a single index label, use [item]. If only one value matches, that scalar is returned; when several values match, a Series comes back:

1
2

s = pd.Series([1, 2, 3, 4, 5, 6], index=['a', 'b', 'a', 'a', 'a', 'c'])
s['a']

a    1
a    3
a    4
a    5
dtype: int64

1

s['b']

2

To fetch the elements for several index labels at once, use [a list of items]:

1

s[['c', 'b']]

c    6
b    2
dtype: int64

When you want the elements between two index labels that each occur only once in the whole index, a slice does the job; note that such a slice includes both endpoints:

1

s['c': 'b': -2]

c    6
a    4
b    2
dtype: int64

If the endpoint labels appear more than once, the index must be sorted before slicing:

1
2
3

5

    s['a': 'b']

    Err_Msg = e

1

b    2
dtype: int64

[b] Series with integer indices

When reading data without explicitly naming a column as the index, pandas creates a default integer index starting at 0. Of course, any set of integers of the right length can serve as an index.

As with strings, using [int] or [int_list] retrieves the element values associated with those index labels:

1
2

s = pd.Series(['a', 'b', 'c', 'd', 'e', 'f'], index=[1, 3, 1, 2, 5, 4])
s[1]

1    a
1    c
dtype: object

1

s[[2,3]]

2    d
3    b
dtype: object

An integer slice, by contrast, selects values by position; like a Python slice, it excludes the right endpoint:

1

s[1:-1:2]

3    b
2    d
dtype: object

[WARNING] A note on index types

To stay out of trouble, avoid using pure floats or any mixed type (a blend of strings, integers, floats, and so on) as an index. Doing so may raise errors or produce unexpected results during specific operations, and there is no real-world motive for it in data analysis either.

[END]

3. The loc indexer

We have looked at selecting columns of a DataFrame; next we turn to selecting rows. For a table there are two indexers: the loc indexer, based on element labels, and the iloc indexer, based on position.

The general form of the loc indexer is loc[*, *], where the first * selects rows and the second selects columns. If you omit the second position and write loc[*], that single * refers to row filtering. Each * slot accepts five kinds of legal objects: a single element, a list of elements, a slice of elements, a Boolean list, and a function; we explain them in turn below.

To demonstrate these operations, we first use set_index to make the Name column the index; other uses of this function are covered in the multi-index chapter.

4. The iloc indexer

iloc works much like loc, except that it filters by position. Its * slots likewise accept five kinds of legal objects: an integer, a list of integers, an integer slice, a Boolean list, and a function. A function must return one of the first four kinds, and its input is again the DataFrame itself.

5. The query method

In pandas you can pass a query expression as a string to the query method; the expression must evaluate to a Boolean list. For complex indexing, this style avoids repeatedly spelling out the DataFrame name to reference columns, so it generally shortens the code without hurting readability.

For example, the compound-condition query from the loc section can be rewritten as follows:

3
4
5

df.query('((School == "Fudan University")&'
         ' (Grade == "Senior")&'
         ' (Weight > 70))|'
         '((School == "Peking University")&'
         ' (Grade != "Senior")&'
         ' (Weight > 80))')

6. Random sampling

If you treat each row of a DataFrame as a sample, or each column as a feature, and the whole DataFrame as the population, the sample function lets you draw a random sample of rows or features. After receiving a large dataset you may want to compute summary statistics to understand its rough distribution, yet doing so on everything can be slow. Because many statistics—the sample mean versus the population mean, for instance—are unbiased estimates under simple random sampling without replacement, you can draw a subset of the table first and use it for an approximate estimate.

The main parameters of sample are n, axis, frac, replace, weights. The first three give the number of items to draw, the axis (0 for rows, 1 for columns), and the sampling fraction (0.3 means drawing 30% of the population).

replace and weights control whether sampling is with replacement and the relative probability of each item; replace = True means sampling with replacement. In the example below, we draw three rows from df_sample with replacement, using the relative magnitude of value as the sampling probability.

1
2

df_sample = pd.DataFrame({'id': list('abcde'), 'value': [1, 2, 3, 4, 90]})
df_sample

1b2
2c3
3d4
4e90
1

4. Constructing multi-level indexes

We have seen the structure of multi-indexed tables and how to slice them. Beyond set_index, how can you build a multi-index yourself? Three common methods are from_tuples, from_arrays, from_product, all of them functions on the pd.MultiIndex object.

from_tuples builds an index from a supplied list of tuples:

1
2

my_tuple = [('a','cat'),('a','dog'),('b','cat'),('b','dog')]
pd.MultiIndex.from_tuples(my_tuple, names=['First','Second'])

MultiIndex([('a', 'cat'),
            ('a', 'dog'),
            ('b', 'cat'),
            ('b', 'dog')],
           names=['First', 'Second'])

from_arrays builds an index from the lists corresponding to each level in the supplied list:

1
2

my_array = [list('aabb'), ['cat', 'dog']*2]
pd.MultiIndex.from_arrays(my_array, names=['First','Second'])

MultiIndex([('a', 'cat'),
            ('a', 'dog'),
            ('b', 'cat'),
            ('b', 'dog')],
           names=['First', 'Second'])

from_product builds an index from the Cartesian product of the given lists:

1
2
3

my_list1 = ['a','b']
my_list2 = ['cat','dog']
pd.MultiIndex.from_product([my_list1, my_list2], names=['First','Second'])

MultiIndex([('a', 'cat'),
            ('a', 'dog'),
            ('b', 'cat'),
            ('b', 'dog')],
           names=['First', 'Second'])

IV. Index arithmetic

1. Rules of set operations

It is often useful to retrieve rows satisfying a condition by means of set operations. Suppose two tables A and B are both indexed by employee number and you want all employees whose IDs lie in the intersection of the two indexes; operations on Index make this easy.

Before that, let us review the four common set operations:

$$\rm S_A.intersection(S_B) = \rm S_A \cap S_B \Leftrightarrow \rm \{x|x\in S_A\, and\, x\in S_B\}$$

$$\rm S_A.union(S_B) = \rm S_A \cup S_B \Leftrightarrow \rm \{x|x\in S_A\, or\, x\in S_B\}$$

$$\rm S_A.difference(S_B) = \rm S_A - S_B \Leftrightarrow \rm \{x|x\in S_A\, and\, x\notin S_B\}$$

$$\rm S_A.symmetric\_difference(S_B) = \rm S_A\triangle S_B\Leftrightarrow \rm \{x|x\in S_A\cup S_B - S_A\cap S_B\}$$

2. General index operations

Because the elements of a set are distinct whereas an index may contain duplicates, call unique first to remove duplicates before performing the operation. Two of the simplest example tables follow:
