DTW was originally used to measure similarity between speech signals. The DTW algorithm is now commonly used to compute the similarity of two time series, especially series of different lengths and different rhythms.

Algorithm

Suppose there are two sequences

$$\mathbf{X}=\{\mathbf{x}_1,\mathbf{x}_{2},\ldots,\mathbf{x}_{n}\} $$$$\mathbf{Y}=\{\mathbf{y}_1,\mathbf{y}_{2},\ldots,\mathbf{y}_{m}\} $$

First, build an $m\times n$ two-dimensional array $W$. Each point $W(i,j)$ in the array is the cumulative distance between $\mathbf{X}_{i}$ and $\mathbf{Y}_{j}$, $\sqrt{ (\mathbf{X}_{i}-\mathbf{Y}_{j})^2 }$. The core idea of DTW is to find, in this distance matrix, the minimum-distance warping path from the start of both sequences to their ends. While searching for that path, several constraints must be satisfied:

  1. Boundary condition: the start must be $w(1,1)$ and the end must be $w(1,1)$; the path has to begin and it has to end.
  2. Continuity: the next valid gray square must be one of the squares in the ring immediately surrounding the current gray square.
  3. Monotonicity: the next valid gray square must lie above and to the right of the current gray square; the path cannot turn back. Suppose the two sequences are $\mathbf{X}=\{1,3,2,4,2\}$ and $\mathbf{Y}=\{0,3,4,2,2\}$. Using the Euclidean distance, the distance between them can be computed directly as: $$ dis = \sqrt{ (1-0)^2+(3-3)^2+(2-4)^2+(4-2)^2+(2-2)^2 }=\sqrt{ 5 } $$

Build the cumulative distance matrix $w$:

  1. First fill the leftmost column, $W(i,0)=dis(\mathbf{X}_{i}-\mathbf{Y}_{0})+W(i-1,0)$
  2. Then fill the bottom row: $W(0,j)=dis(\mathbf{X}_{0},\mathbf{Y}_{j})+W(0,j-1)$
  3. Finally fill the cells in the middle of the table: $W(i,j)=dis(\mathbf{X}_{i},\mathbf{Y}_{j})+\min(W(i-1,j),W(i,j-1),W(i-1),W(j-1))$
  4. Then, using the cumulative distance matrix just built, search for the warping path from the upper-right corner to the lower-left corner, and take the smaller of the three cells toward the lower left as the next node.
  5. The resulting alignment is $\{(\mathbf{x}_{1},\mathbf{y}_{1}), (\mathbf{x}_{2},\mathbf{y}_{2}),(\mathbf{x}_{3},\mathbf{y}_{2}),(\mathbf{x}_{4},\mathbf{y}_{3}),(\mathbf{x}_{5},\mathbf{y}_{4}),(\mathbf{x}_{5},\mathbf{y}_{5})\}$

import numpy as np
import math
# Dynamic Time Warping
def dtw(x, y):
    # x and y are both 1D arrays
    # dist_func is a function that takes two arguments and returns a number
    # (e.g. lambda x, y: abs(x - y))
    # initialize DTW matrix
    DTW = np.zeros((len(x), len(y)))  
    # fill in first row and column
    for i in range(len(x)):
        DTW[i, 0] = dist_func(x[i], y[0])+DTW[i-1, 0]
    for j in range(len(y)):
        DTW[0, j] = dist_func(x[0], y[j])+DTW[0, j-1]
    for i in range(1,len(x)):
        for j in range(1, len(y)):
            DTW[i, j] = dist_func(x[i], y[j]) + min(DTW[i-1, j], DTW[i, j-1], DTW[i-1, j-1])
    path = []
    i = len(x)-1
    j = len(y)-1
    while True:
        if i>0 and j > 0: # if not at the top left
            path.append((i,j))
            if DTW[i-1, j] == min(DTW[i-1, j], DTW[i, j-1], DTW[i-1, j-1]):
                i -= 1
            elif DTW[i, j-1] == min(DTW[i-1, j], DTW[i, j-1], DTW[i-1, j-1]):
                j -= 1
            else:
                i -= 1
                j -= 1
        elif i == 0 and j == 0:
            path.append((i,j))
            break
        elif i == 0:
            path.append((i,j))
            j = j-1
        elif j == 0:
            path.append((i,j))
            i = i-1
    return path
def dist_func(x,y):
    result = (x-y)**2
    return result
if __name__ == '__main__':
    x = [1, 1, 3, 3, 2, 4]
    y = [1, 3, 2, 2, 4, 4]
    print(dtw(x, y))
