1 First Look at C++

1.1 The First C++ Program

Writing a C++ program takes four steps:

  • Create a project
  • Create a file
  • Write the code
  • Run the program

Visual Studio is the main tool we use to write C++ programs. Open it first.

1.2 Comments

Purpose: add notes and explanations in the code so that you or other programmers can read it more easily.

Two forms

  1. Single-line comment: // description
    • Usually placed above a line of code, or at the end of a statement, to ==explain that line==
  2. Multi-line comment: /* description */
    • Usually placed above a block of code to ==explain that block as a whole==

Tip: when the compiler compiles the code, it ignores the contents of comments.

1.4 Constants

Purpose: record data in the program that cannot be changed.

C++ defines constants in two ways:

  1. #define macro constant: #define constant_name constant_value

    • ==Usually defined near the top of the file== to represent a constant

  2. A variable qualified by const: const data_type constant_name = constant_value

    • ==Usually add the keyword const before the variable definition== to qualify that variable as a constant, which cannot be modified

1.6 Identifier Naming Rules

Purpose: C++ has its own rules for naming identifiers (variables and constants).

  • An identifier cannot be a keyword
  • An identifier may contain only letters, digits, and underscores
  • The first character must be a letter or an underscore
  • Letters in an identifier are case-sensitive

Suggestion: when naming an identifier, aim for a name whose meaning is clear at a glance, so that you and others can read it more easily.

2 Data Types

C++ requires you to specify the corresponding data type whenever you create a variable or a constant; otherwise it cannot allocate memory for the variable.

Purpose: an integer variable represents data of an ==integer type==.

2.4 Character Type

Purpose: a character variable is used to display a single character.

Syntax: char ch = 'a';

Note 1: when displaying a character variable, enclose the character in single quotes. Do not use double quotes.

Note 2: single quotes can contain only one character, not a string.

  • In both C and C++, a character variable occupies only ==1 byte==.
  • A character variable does not store the character itself in memory. Instead, the corresponding ASCII code is stored in the memory location.

4 Program Flow Structures

C/C++ supports the three most basic program execution structures: ==sequence structure, selection structure, and loop structure==

  • Sequence structure: the program executes in order, without jumps
  • Selection structure: the corresponding functionality is executed selectively depending on whether a condition is met
  • Loop structure: a section of code is executed repeatedly depending on whether a condition is met
