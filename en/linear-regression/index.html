Linear Regression

Introduction

Linear regression is a typical method among linear models.

Basic Principles

Given a data set $D = \{(x_1,y_1),...,(x_m,y_m) \}$ of inputs $x$ and outputs $y$, where $y_{i}\in \mathbb{R}$. A linear regression model assumes that the data are linearly distributed, so the goal is to learn a linear model that minimizes the error between the predicted values and the true values. Assume that the output and the input in linear regression are related by

$$ y = wx_i+b $$

Least squares minimizes the mean squared error:

$$ \begin{aligned} (w^*,b^*)=\arg\min\sum_{i=1}^{m}(y-y_i)^2=\arg\min\sum_{i=1}^{m}(wx_i+b-y_i)^2 \end{aligned}\tag{1}\label{eq1} $$

The closed-form solutions for the parameters $w^*$ and $b^*$ can be obtained from $\eqref{eq1}$.

$$ \begin{aligned} \frac{\partial L(w, b)}{\partial w} & =\frac{\partial}{\partial w}\left[\sum_{i=1}^{m}\left(w x_{i}+b-y_{i}\right)^{2}\right] =\sum_{i=1}^{m} \frac{\partial}{\partial w}\left[\left(y_{i}-w x_{i}-b\right)^{2}\right] \\ & =\sum_{i=1}^{m}\left[2 \cdot\left(y_{i}-w x_{i}-b\right) \cdot\left(-x_{i}\right)\right] =\sum_{i=1}^{m}\left[2 \cdot\left(w x_{i}^{2}-y_{i} x_{i}+b x_{i}\right)\right] \\ & =2 \cdot\left(w \sum_{i=1}^{m} x_{i}^{2}-\sum_{i=1}^{m} y_{i} x_{i}+b \sum_{i=1}^{m} x_{i}\right) \end{aligned} $$$$ \begin{aligned} \frac{\partial L(w, b)}{\partial b} & =\frac{\partial}{\partial b}\left[\sum_{i=1}^{m}\left(w x_{i}+b-y_{i}\right)^{2}\right] =\sum_{i=1}^{m} \frac{\partial}{\partial b}\left[\left(y_{i}-w x_{i}-b\right)^{2}\right] \\ & =\sum_{i=1}^{m}\left[2 \cdot\left(y_{i}-w x_{i}-b\right) \cdot(-1)\right] =\sum_{i=1}^{m}\left[2 \cdot\left(-y_{i}+w x_{i}+b\right)\right] \\ & =2 \cdot\left(-\sum_{i=1}^{m} y_{i}+\sum_{i=1}^{m} w x_{i}+\sum_{i=1}^{m} b\right) =2 \cdot\left(m b-\sum_{i=1}^{m}\left(y_{i}-w x_{i}\right)\right) \end{aligned} $$

This yields the following expressions for the weight $w^*$ and the bias $b^*$:

$$ \begin{aligned} w^{*}&=\frac{\sum_{i=1}^{m} y_{i}\left(x_{i}-\bar{x}\right)}{\sum_{i=1}^{m} x_{i}^{2}-\frac{1}{m}\left(\sum_{i=1}^{m} x_{i}\right)^{2}} \\ b^{*}&=\frac{1}{m} \sum_{i=1}^{m}\left(y_{i}-w x_{i}\right) \end{aligned} $$

Equation $\eqref{eq1}$ is the vector form of linear regression. In practice, linear regression is usually written in matrix form. First, the inputs $x$ are concatenated into a matrix:

$$ \boldsymbol{X}=\left(\begin{array}{ccccc} x_{11} & x_{12} & \cdots & x_{1 d} & 1 \\ x_{21} & x_{22} & \cdots & x_{2 d} & 1 \\ \vdots & \vdots & \ddots & \vdots & \vdots \\ x_{m 1} & x_{m 2} & \cdots & x_{m d} & 1 \end{array}\right)=\left(\begin{array}{cc} x_{1}^{\mathrm{T}} & 1 \\ \vdots & \vdots \\ x_{m}^{\mathrm{T}} & 1 \end{array}\right) $$

The output vector $y$ is stacked accordingly as $\mathbf{y}=(y_1;y_2;...;y_m)$. The optimization objective then takes the following matrix form:

$$ w^*=\arg\min(\mathbf{y}-\mathbf{X}\hat{w}^T)(\mathbf{y}-\mathbf{X}\hat{w}) $$

Differentiating with respect to the weight matrix and the bias matrix yields:

$$ \begin{aligned} \frac{\partial L}{\partial w}&=-\mathbf{X}^T\mathbf{y}-\mathbf{X}^T\mathbf{y}+(\mathbf{X^TX}+\mathbf{X^TX})\hat{w}\\ \frac{\partial L}{\partial b}&=2\mathbf{X}^T(\mathbf{X}\hat{w}-\mathbf{y}) \end{aligned} $$

The analytical solution, the normal equation, follows directly from the gradient:

$$ \hat{w}=(\mathbf{X^{T}X})^{-1} \mathbf{X}^{T}\mathbf{y} $$

# Import the NumPy module
import numpy as np
### Define the main part of the model
### This includes the linear regression formula, the mean squared loss, and the partial derivatives of the parameters
def linear_loss(X, y, w, b):
	''' Inputs:
	X: input variable matrix
	y: output label vector
	w: variable parameter weight matrix
	b: bias
	Outputs:
	y_hat: predictions of the linear regression model
	loss: mean squared loss
	dw: first-order partial derivative of the weight coefficients
	db: first-order partial derivative of the bias
	'''
	# Number of training samples
	num_train = X.shape[0]
	# Number of training features
	num_feature = X.shape[1]
	# Linear regression predictions
	y_hat = np.dot(X, w) + b
	# Mean squared loss between the predictions and the true labels
	loss = np.sum((y_hat-y)**2) / num_train
	# First-order gradient of the mean squared loss with respect to the weight coefficients
	dw = np.dot(X.T, (y_hat-y)) / num_train
	# First-order gradient of the mean squared loss with respect to the bias
	db = np.sum((y_hat-y)) / num_train
	return y_hat, loss, dw, db
### Initialize the model parameters
def initialize_params(dims):
	'''
	Input:
	dims: feature dimension of the training data
	Outputs:
	w: initialized weight coefficients
	b: initialized bias
	'''
	# Initialize the weight coefficients to the zero vector
	w = np.zeros((dims, 1))
	# Initialize the bias to zero
	b = 0
	return w, b
### Define the training procedure of the linear regression model
def linear_train(X, y, learning_rate=0.01, epochs=10000):
	''' Inputs:
	X: input variable matrix
	y: output label vector
	learning_rate: learning rate
	epochs: number of training iterations
	Outputs:
	loss_his: mean squared loss at each iteration
	params: dictionary of optimized parameters
	grads: dictionary of gradients of the optimized parameters
	'''
	# Empty list for recording the training loss
	loss_his = []
	# Initialize the model parameters
	w, b = initialize_params(X.shape[1])
	# Iterative training
	for i in range(1, epochs):
		# Predictions, mean squared loss, and gradients at the current iteration
		y_hat, loss, dw, db = linear_loss(X, y, w, b)
		# Parameter update by gradient descent
		w += -learning_rate * dw
		b += -learning_rate * db
		# Record the loss at the current iteration
		loss_his.append(loss)
		# Print the current loss every 10,000 iterations
		if i % 10000 == 0:
			print('epoch %d loss %f' % (i, loss))
		# Save the parameters optimized at this iteration to a dictionary
		params = {
			'w': w,
			'b': b
				}
		# Save the gradients at this iteration to a dictionary
		grads = {
			'dw': dw,
			'db': db
				}
	return loss_his, params, grads

# Import the load_diabetes module
from sklearn.datasets import load_diabetes
# Import the function that shuffles the data
from sklearn.utils import shuffle
# Load the diabetes data set
diabetes = load_diabetes()
# Get the inputs and the labels
data, target = diabetes.data, diabetes.target
# Shuffle the data set
X, y = shuffle(data, target, random_state=13)
# Split the data into a training set and a test set in an 8:2 ratio
offset = int(X.shape[0] * 0.8)
# Training set
X_train, y_train = X[:offset], y[:offset]
# Test set
X_test, y_test = X[offset:], y[offset:]
# Reshape the training labels into a column vector
y_train = y_train.reshape((-1,1))
# Reshape the test labels into a column vector
y_test = y_test.reshape((-1,1))
# Print the shapes of the training and test sets
print("X_train's shape: ", X_train.shape)
print("X_test's shape: ", X_test.shape)
print("y_train's shape: ", y_train.shape)
print("y_test's shape: ", y_test.shape)
# Train the linear regression model
loss_his, params, grads = linear_train(X_train, y_train, 0.01, 200000)
# Print the model parameters obtained after training
print(params)
### Define the prediction function of the linear regression model
def predict(X, params):
	''' Inputs:
	X: test set
	params: parameters learned by the model
	Output:
	y_pred: model predictions
	'''
	# Get the model parameters
	w = params['w']
	b = params['b']
	# Predict
	y_pred = np.dot(X, w) + b
	return y_pred
# Predictions on the test set
y_pred = predict(X_test, params)

### Define the R2 score function
def r2_score(y_test, y_pred):
	'''
	Inputs:
	y_test: labels of the test set
	y_pred: predictions on the test set
	Output:
	r2: R2 score
	'''
	# Mean of the test-set labels
	y_avg = np.mean(y_test)
	# Total sum of squares
	ss_tot = np.sum((y_test - y_avg)**2)
	# Residual sum of squares
	ss_res = np.sum((y_test - y_pred)**2)
	# Compute R2
	r2 = 1- (ss_res/ss_tot)
	return r2
	# Compute the R2 score on the test set
print(r2_score(y_test, y_pred))

# Import the linear regression module
from sklearn import linear_model
from sklearn.metrics import mean_squared_error, r2_score
# Create a model instance
regr = linear_model.LinearRegression()
# Fit the model to the training data
regr.fit(X_train, y_train)
# Model predictions
y_pred = regr.predict(X_test)
# Print the mean squared error of the model
print("Mean squared error: %.2f"% mean_squared_error(y_test, y_pred))
# Compute the R2 score
print('R Square score: %.2f' % r2_score(y_test, y_pred))
